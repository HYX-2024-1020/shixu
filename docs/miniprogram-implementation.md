## 接口边界

| 接口                                 | 行为                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------ |
| GET /api/v2/status                   | 公开应用/协议/数据版本、epoch 与当前能力；AI、附件、微信登录明确为未接入 |
| POST /api/v2/devices                 | 独立个人口令换取 30 天设备令牌；失败限速；不是微信登录                   |
| GET /api/v2/changes?cursor=…&epoch=… | 增量拉取记录与删除标记，支持分页                                         |
| POST /api/v2/operations              | 提交 epoch 与单个操作；包含 opId、id、type、baseVersion，put 另含 data   |
| DELETE /api/v2/device                | 撤销当前设备令牌，不删除资料                                             |

`put` 对未提供的顶层字段保留原值，对 `itemState` 按事项/字段合并。`delete`、`restore`、`purge` 是显式操作，不接受夹带内容更新。操作去重与资料写入、全局版本在同一事务中提交。确认重放返回当前记录，不从去重记录重新泄露已永久删除的原文。

这是单资料空间服务。当前采用个人服务口令完成首次授权，不开放按客户端自报 openid 进入资料空间的接口。微信登录与桌面配对需后续单独实现。
