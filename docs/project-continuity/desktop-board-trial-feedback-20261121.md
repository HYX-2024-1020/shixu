# 桌面看板试用反馈（2026-11-21）

本轮反馈来自用户实际使用时提供的截图和说明，跟踪 [#117](https://github.com/HYX-2024-1020/shixu/issues/117)。现有实现位于 [Draft PR #129](https://github.com/HYX-2024-1020/shixu/pull/129) 的 `feat/desktop-board-integration`，留存时头提交为 `f5f5418`，对应 0.3.31 候选。[该提交的六项 CI](https://github.com/HYX-2024-1020/shixu/actions/runs/43734449137)已通过。用户提供了试用反馈，本轮未核验安装文件来源，也未进行产品修改。

用户要求按反馈修复、自测、交新版试用，并按后续反馈迭代。用户明确认可体验后再做最终验收和合并。旧安装手册中直接转入收尾的步骤由这项新决定取代。

## 整体原则

主程序「看板」负责切换视图和调整设置，悬浮窗负责看内容和直接操作。保留现有功能，以减少层层套框、重复标题、副标题、小字和常驻状态来腾出空间。常用操作就近可点，低频操作收进菜单或主程序；确实需要处理的失败仍要有明确提示。四个悬浮视图都按这条原则自查。

## 反馈与验收

| 编号 | 用户要求与可观察结果 |
| --- | --- |
| 01 主程序入口 | 用户认可横向展开的布局方向，具体区域和内容仍待考量。标题旁的「日常规划」选择改为「小条／窄栏／面板／DDL」选择器，选哪项，主程序就显示对应板块。右上常驻醒目的黄色「打开悬浮看板」大按钮，一键打开当前选中的板块。首页去掉单独的「打开资料库」，资料库在「面板」里。规划切换、新建等低频操作放在主程序的适当位置。 |
| 02 滚动条 | 四种悬浮视图都隐藏可见滚动条；内容溢出时可用滚轮滚到底。用长列表和不同窗口尺寸检查。 |
| 03 贴边拖动 | 四种模式贴住屏幕边缘后都难以拖离。核对原生停靠逻辑，向内拖时应立即跟手，能够一次拖离。检查左右屏幕边缘及适用的多屏情况。 |
| 04 悬浮窗控件 | 移除悬浮窗的四视图切换和「窗口与规划」大块。规划管理、最近删除、位置锁定、启动恢复、密度和透明度在主程序调整。悬浮窗优先保留紧凑的置顶、关闭与该视图直接需要的写入和内容操作。 |
| 05 窄栏短期 | 事项是独立小卡片，利用卡片轮廓与间距区分。取消「眼前要做的事」等重复外框和行隔线，少用内边距，优先显示标题。常用勾选与新增就近可点；省掉重复的「手写 · 短期计划」。 |
| 06 窄栏长期 | 每个父计划是一张清楚的卡，突出计划名、实际子事项、直接添加及勾选。去掉「一步步推进」、常驻联动解释、空计划的「0/0 已完成」和「当前步骤已全部完成」等。改名、完成父计划、归档、删除可收进就近菜单。保留子事项联动、归档恢复及父计划手动完成行为。 |
| 07 小条 | 展开后只看一件件事项，可就地勾选和收起；从悬浮小条移走显示规则、固定事项下拉、待完成数量、最近 DDL 等区域。显示规则和固定事项在主程序的「小条」板块设置。 |
| 08 面板资料库 | 复用「世界」卡片拖动的交互，按放下后的顺序持久保存，重启仍保留。各项资料可重命名，建议改显示名并保留原文件名、扩展名和引用。取消看板内预览，「打开」交给 Windows 中该文件类型的默认应用。通过既有原件、权限和所属空间校验实现，缺件或打开失败时简短反馈。 |
| 09 DDL | 内容使用窗口可用宽度，修复右侧大块留空，具体原因以代码和实测为准。保留日期筛选。卡片主要显示事项名、一次截止时间和剩余或逾期状态，去掉重复的「截止雷达」「DEADLINE / 时间有出处」和说明小字。需要区分时简短标明推定时刻，保留现有日期区间与人工覆盖规则。 |
