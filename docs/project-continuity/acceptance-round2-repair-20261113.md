- 旧任务：Windows `createAI`复用暂停任务ID却未提交continue；用户重试现在使用原任务的代次、输入版本及维护凭据明确续接，刷新不自动续接，不生成替代任务。费用不明、任务名额和其他安全门禁保留。

- 原件：旧下载仅写内部缓存；现增加原生另存为和目标路径/取消回执。旧续期从当前时间重设30天，同日几乎无变化；现从已有期限或当前时间较晚者延长30天，操作重放不重复延长。真实安装入口仍待验证，不能将合成回归当用户问题已彻底解决。
- 设置：横向单分区页签；整理任务移至世界入口。首次连接/用途未完成时接续引导，用途与期限分别记录，不代勾；未授权仍可手动管理。
- 小组：独立持久化的世界布局记录，支持空组、改名、排序、删除、一卡多组及同组顺序；隐藏/恢复类型入口不删资料。模型标签与用户关系分离。
- 合并：新增完整主卡与源子项模型、原件来源引用、预览与撤销；服务端在同一租户安全事务中修改全部目标，拒绝陈旧版本/重复目标。合并主卡有新编辑时必须明确保留为独立卡或取消撤销。AI协议新增merge待确认输出及投递/小组/选卡范围，尚须完成端到端回归。
- 告警：普通材料失败只留任务历史；近10分钟至少3账号/5任务的服务异常持续2分钟才升级。账本、费用不明等高风险仍独立立即升级。持续告警沿原记录去重，恢复保留历史。管理视觉沿主程序纸黄、硬边框及明确按钮反馈。
