主程序增加独立「看板」页，管理多份命名规划并自动保存。启用悬浮看板可继续上次、选择已有或新建空白，旧规划保留。事件（规划）与 DDL 是两个选项卡：事件页初始空白，自己选择主程序事项加入或手写；DDL 默认读取主程序全部 DDL，并展示当前规划内有日期的手写事项、标明来源。选入事项与来源同步，移出不删除来源；手写事项归规划所有，不混入桶、普通事项或主程序普通 DDL，以后可主动转入。

首版是一块可拖动、拉伸、置顶/取消置顶、隐藏/恢复、锁定布局的看板，支持小条/窄栏/面板、快捷键、预设布局及模块自由组合。事件页有待办、长期挂念、随手记，截止雷达放 DDL 页。模块可重复添加、筛选、调整大小/顺序/折叠。小条自选内容不轮播。沿用拾序视觉，调透明度和密度，文字保持清楚。不做声音、弹窗、定时催促或回顾提醒。

长期子事项由用户手动添加，不用 AI 生成。勾选后原位淡化+划线、记录完成日期，跨日保留、可撤销；可单条/批量归档，归档仍可查看和恢复。完成全部现有步骤不自动完成父事项，不弹窗催促。随手记先存草稿，可转为看板事项；普通增删改直接保存不调用模型，长文本仅主动选择整理。常用编辑在看板内完成，原文附件和复杂详情进入主程序。

主程序收托盘后看板继续，明确退出拾序一起退出；关闭看板不丢规划。目标包括 Apple Music 参考场景全屏后看板仍可见，须调查平台官方能力和实际验证，不先承诺所有独占全屏兼容。现有禁止 computer-use/本机桌面 UI 自动操作约束仍有效；使用获准的隔离自动测试和 CI，确需用户验证时说明具体步骤，不自行操作用户桌面。
