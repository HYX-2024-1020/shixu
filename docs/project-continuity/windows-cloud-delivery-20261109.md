## 本批实现

- 新的安装版私有连接配置只由主进程读取，使用 Windows OpenSSH、固定主机密钥校验及专用转发身份；不启用开发用服务地址环境覆盖。端口监听确认属于本次 SSH 进程后才发送请求，断线使在途请求失败并重连，离线队列保留。
- Windows 私有云模式使用全新专属 profile，不读取或上传旧 profile；旧资料不迁移、不删除其他账号数据。
- 云服务管理监听固定回环，沿 SSH 转发访问。复用现有桌面控制台快捷方式、图标及管理员身份，不开放公网管理页。
- 控制台界面、字体与 Node 运行时固定安装在本机；本机网关只转发受来源/CSRF保护的管理 API 至 SSH 隧道，不打开业务库或持有管理员密码。避免窄带云主机的大字体传输阻塞首屏，沿用本机8789入口；每次启动核对包内文件，重复打开复用经PID/启动时间验证的进程。
- 真实 CPU 差分、内存、磁盘 statfs、服务进程、调度积压和账号/账本统计；来源、采样时间、过期及失败状态可见。备份监测和月预算未接入时明确标注。
- 人工控制使用独立运维数据库，逐次付费预留前执行全站/个人组合门禁，覆盖读取、事项对话、视觉核对、合并和关联。已发调用结算保留；人工恢复不改费用、unknown 或安全控制，不唤醒旧任务。写操作幂等与追加审计持久化。
- 告警独立子页、导航未解决数量、总览简短摘要；真实资源、积压、费用和价格门禁持续问题去重，恢复保留历史。控制在页面/用户抽屉中展开确认，无大弹窗。
- 实际安装联验发现并修正 systemd 重设暂存目录权限的问题；读取器仍坚持0700与完整隔离。补齐私有云客户端轮询合并和限流退避，不提高服务端请求或费用门槛；429/503读取失败保留既有任务及付费状态。读取/模型失败纳入持久告警，已读独立于恢复。
- 未纳入首批的额度追加、密码重置、设备协助在 HTTP 模式禁用；任务详细处置、备份恢复、重启不顺带开放。
