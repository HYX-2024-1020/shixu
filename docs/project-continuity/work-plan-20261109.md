## 当前优先级

1. **先交付 Windows 客户端、现有阿里云服务与统一管理控制台的真实使用闭环。** 用户能够使用实际安装的 Windows 客户端，并在控制台观察、管理同一套服务。
2. 随后推进小程序自检、优化和手机测试。先解决不依赖服务器的功能，代理修复明显问题后再请用户体验。
3. 控制台首个闭环完成后，回到普通用户端的实际体验；任务详细处置、备份恢复、运维等管理能力按需要分批补齐。

域名备案尚未通过是用户提供的现状，不把备案完成作为全部工作的共同前置。Windows 的可用连接方式由代理调查并实现；不能把受控连接写成正式公网发布，也不能将现有开发专用覆盖直接放进安装版。小程序的网络和手机测试能力另行核实。

Windows 和小程序继续共同演进，但允许交付顺序不同，不要求两端等备案后一起上线。保留旧成果与回归，不重新开一个产品。

## 用户和代理的分工

用户负责统筹方向、交付优先级和实际体验判断。代理负责调查代码和环境、技术方案、交互细节、异常规则、实现、回归、PR、安装部署证据及接续维护。

普通细节由代理自行决策，不逐项提问，不过度防御。只有明显改变产品方向、扩大管理权限、改变数据用途或扩大交付范围时，提出具体方案供用户判断。历史需求和已有成果允许提出“保留、暂缓交付”的建议，用户集中判断优先级；总清单不自动成为全部执行队列。

## 真实连接与资料重置

本阶段目标包含实际 Windows 安装版更新、现有阿里云服务的接入与所需部署，以及现有控制台安装更新，不以源码、临时预览或模拟接口代替。实施时先核对实际部署、安装及版本，不从旧 checkout 打包送达。

用户明确允许其历史业务资料删除重来，**不做历史资料迁移**。代理先核对目标确属拾序及该用户的业务资料，再在接入过程中按全新资料初始化；不波及其他账号、其他项目或既有代码成果。运行环境和必要配置复用，费用及安全记录按现有一致性契约处理。该授权不等于本轮已执行删除，也不要求先阅读用户旧正文。

验收使用合成材料及可核对的操作。真实模型付费验证沿用明确的费用授权及预算门禁；不把个人资料默认上传作为验收方式。凭据不进入公共仓库、文档或日志。

## 统一管理控制台的定位

统一汇总拾序所在阿里云主机的运行监测、拾序服务运维与业务管理。阿里云实例开关机、重装、续费及云资源购买继续使用阿里云官方控制台。

沿用现有桌面「拾序管理控制台」快捷方式，通过受保护连接访问服务器。近期不开放公网管理页面，只供用户本人使用一个独立管理员账号；多人管理员及角色分工不在首批范围。

完整页面结构：服务总览、用户管理、任务管理、存储与备份、运维与审计，以及新增的独立告警中心。复用现有视觉、登录、组件和接口适配层。

管理端沿用[阶段 A 契约](../stage-a/contracts.md)的统计、元数据及错误码边界，不提供用户正文、原件下载或导出，安全审计不可删除。

## 告警和控制交互

首批只做控制台内提醒，不建设关闭控制台后的外部通知。告警是独立子页面，**不使用大弹窗**；导航显示未解决数量，总览仅放简短摘要及入口。

页面呈现严重程度、对象、发生时间、最近检测时间、处理建议和相关处理入口。同一持续问题更新原记录，避免重复刷屏；故障恢复后标为已恢复并保留历史。已读不表示故障已解决。采样频率、异常阈值及其他普通实现选择由代理按环境确定。

暂停等控制操作在当前页面展开小确认区，说明对象和影响，确认后执行。以服务端结果判定成功，原位显示失败原因和可用的重试入口；不把按钮状态当成操作成功。

## 人工暂停与恢复语义

- 人工暂停阻止对应范围内后续新的付费模型派发，包括已排队任务的下一步。
- 已发出的请求可能继续返回并产生费用，按可信收据结算；不承诺暂停能撤销已发费用。
- 保留进度、已有结果和资料；普通登录、查看、编辑及同步继续可用。
- 全站暂停与个人暂停独立，任意一项仍暂停时，该用户不能发起新的 AI 调用；恢复其中一个不解除另一个。
- 人工恢复不清除账本、费用不明或其他安全门禁，不清除已结算费用和 unknown 预留。
- 恢复只重新开放 AI 使用权限，因人工暂停而停下的原任务由用户主动继续。新提交任务遵守其他门禁正常受理，控制台展示等待继续的任务情况。

现有演示界面曾写“恢复后按队列顺序继续”，实施时须同步修正文案和回归，不能把演示文案当成已实现行为。

## 后续小程序工作线

代理先自检并修复卡牌折叠、拖动、UI、文件上传等浅显问题，保留已合入修复，不用旧源码整份覆盖。之后交用户手机测试，再按反馈迭代。

用户提出使用微信开发工具的手机测试能力，并增加自行填写 API Key 的测试入口。代理先核实官方能力、真机网络限制和凭据保护，区分开发工具、手机、服务器及模型链路，不能预先宣称手机直连模型一定可行。该测试入口不自动扩成正式公网产品设计。
