## 小程序依赖例外和后续

本轮三端既定能力无借小程序依赖而后置的项目。仅微信官方身份原生登录/重装、微信本地文件空间和微信手机网络/交互验证依赖微信客户端，属于后续小程序阶段，当前不开发小程序。

本版本交用户集中总体验收，再集中处理三端反馈，之后才进入小程序。连接仍为现有受保护SSH，依赖主机和SSH网络，不是正式公网推广。实例购买、开关机、重装和续费继续由阿里云官方控制台负责。
