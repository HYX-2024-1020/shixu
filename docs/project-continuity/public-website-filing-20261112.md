## 公安备案后续

公安平台已有个人主体申请，新办网站表单仍需完善。网站准备完成后，由用户核对本人信息/证件材料，取得域名证书，并按实际页面填写网络接入商和域名注册商。

可核对字段：网站名、ICP备案号、根域名、www首页、公网IP、中文简体。域名注册日期/到期日可用注册局RDAP核对，但不能代替平台要求上传的域名证书。网站类型/交互式服务按本网站真实功能选择；涉及整个主体面向公众提供生成式AI服务的问题，须结合实际服务对象和客户端开放情况核对，不能一概按静态页面选择“否”。

官方公开指引：[阿里云公安备案步骤](https://help.aliyun.com/zh/icp-filing/basic-icp-service/quick-start-for-public-security-network-filing-for-personal-websites)、[公安机关网站内容要求](https://ga.sz.gov.cn/ZT/HLWSYSQ/CJWT/content/post_11490792.html)、[网站开通日期填写说明](https://ga.sz.gov.cn/ZT/HLWSYSQ/CJWT/content/post_10422061.html)。这些说明不能保证个案审核结果，也不表示客户端/小程序的其他备案已完成。

用户提交并审核通过后，再按平台提供的真实公安备案号、图标和查询链接更新网站页脚。不生成虚假编号，不自动提交本人声明或身份照片。
