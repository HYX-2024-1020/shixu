## 已确认流程边界

### 默认卡与普通卡

默认卡是失败后的待选择状态，不是永久错误横幅；世界计数、搜索与筛选必须能理解其存在。选择保留、删除或重试互斥，重复点击/响应丢失不重复处置。保留后失败不再成为待处理任务，不持续催促联系管理员；保留后仍可手动改内容，原件与来源可查看。

重试保留可信已付费进度；已结算处理不重复收费，确需新增调用才计费。此约定不等于失败免费、不清账本、不解除费用不明或安全门禁。默认卡处置、结果发布和迟到响应要一致，避免用户删卡后又被迟到结果复活。

### 小组、类型与合并

类型描述内容性质，小组承载用户主题规划，合并改变卡片数量，三者分离。新投递可由AI建议小组；已确认名称及归属保持，明确要求重新分组时才预览确认。隐藏系统类型入口不是删除类型或资料。空小组也不能因暂时无卡被自动抹掉。

AI范围包括当前卡、指定小组、同次投递、选定卡及账号范围。对超范围要求先准确列出目标再确认，不因自然语言请求就暗中读写其他卡。范围、读取覆盖和遗漏有说明，账号范围也不等于所有附件已重读，不猜同名身份。

合并前展示目标和变化，一张主卡内部保留子项的独立要求、日期和完成状态，附件/来源不丢；源卡退出正常列表，避免重复展示。未有后续修改可直接撤销；有后续修改先展示影响，选择保留新增内容为独立卡或取消撤销。不能静默丢内容或自动复制大量卡片。陈旧目标、并发修改、删除或跨账号目标应拒绝而非部分写入。

### 管理员与存储

代理负责制定可解释的风险等级、持续窗口和升级阈值，不再让用户拍技术数字。判断维度为影响范围、持续性、是否需管理权限，以及账号安全、费用一致性、资料完整性和服务可用性风险。普通可自助问题只留痕；孤立无可读内容不应自动打断管理员。必要单账号高风险仍可升级，但非任何一次失败都告警。告警需包含对象、影响、依据、可执行措施及恢复证据，已读不等于已解决。

安全释放清理符合已说明保留规则、无有效引用且可释放的内容，优先临时文件、过期缓存及符合保留策略的原件/旧备份。保留策略由代理结合现有容量和契约制定并展示；本访谈没有批准任意新增固定TTL、重写现有期限或销毁某账号资料。真正销毁有效业务资料不藏在释放按钮中，也不因历史“本人资料可重来”授权扩大到其他用户。

原件期限不等于卡片期限；到期清理附件不能连带删卡片、手动内容或已确认事项。保护有效引用、共享原件、最后可用备份和在途执行；清理不足时阻止继续占用的上传并准确解释，不应连手动编辑/查看都不可用。
