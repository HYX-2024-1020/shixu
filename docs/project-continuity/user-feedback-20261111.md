## 范围与状态

- 范围为现有Windows客户端、阿里云服务端、本地统一管理控制台；先集中修复、集成、实际部署安装并自测，再交用户复验，之后才进入小程序。本轮不开发或发布小程序。
- 以下C01—C28中，仅临时投喂阻断已另行修复（见末节）；其余是待整改缺陷、体验改良或明确新增需求，不能标为已修复。尤其C19是明确扩大卡片AI能力的需求，不应伪装成现有能力。
