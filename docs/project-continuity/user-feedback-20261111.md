# 0.3.25 用户集中体验记录

用户逐条反馈期间只记录，结束后再按用户指令整理给新对话的修改提示词。语音听写中的“时序”“云端演件”“飞鹰狐”等按上下文记为“拾序”“云端原件”“绯樱狐”。

## 已记录反馈

1. 管理控制台运行后的任务栏图标应使用现有桌面快捷方式的“序”字图标。桌面快捷方式本身正确。
2. “资料用途与保存期限”的勾选框位置与文字脱节，勾选的作用和后续影响不清楚。
3. 登录应独立、简洁、可靠，并清楚显示已登录及当前账号。其余功能按用途放入齿轮或现有时间栏入口。减少大量小字与混杂操作，参考成熟软件的操作习惯。云端原件的下载、续期30天、删除点击后无明显反应，文字颜色和字体难以辨认是否可点，须核查实际功能和反馈。
4. 皮肤模型本身无需调整。鲸鱼和绯樱狐的长演出应单击开始、再次单击暂停，避免连续点击反复触发或多次点击才暂停。“冰冰冰”保持现有方式。绯樱狐后段出现以前没有的嘈杂声音，需检查原音轨及播放链路。

整体方向是主动检查并改良相关界面、流程和反馈，使产品简洁、可靠、易理解。上述例子用于指明改良方向，后续整改应覆盖同类问题。
