# E 阶段管理台前端（首批交付）

更新：2026-11-04，北京时间。任务分支 `feat/e-admin-ui`。本页记录管理网页前端的首批交付、接口需求与其余页面结构；后端 `/admin/v1` 由独立后端任务接续，未就绪前前端使用合成数据适配层。

依据：[原方案 §9–§12](https://github.com/HYX-2024-1020/shixu/blob/da28c1fbf76a0e7c5aae15228d25ecef6cca3ad9/docs/server-client-plan-2026-10-28.md) 与 [阶段 A 契约](../stage-a/contracts.md)（管理路由回环监听、独立会话、只读统计/元数据、不提供用户正文/导出）。

## 交付范围（首批）

- 登录：独立管理员登录、失败提示（保留输入）、会话过期自动回登录并说明原因、退出。
- 服务总览：需要处理的问题置顶（含下一步入口）；服务状态、资源占用（磁盘 80% 阈值高亮）、任务队列、费用（¥、站点预算、预留中）、备份（成功/失败时间、保留份数与到期、维护原因与暂停状态）。
- 用户管理：列表（搜索/状态筛选/分页）、详情抽屉（累计额度、已消费、预留中、余额四格账本）、追加额度、暂停/恢复 AI、设备撤销协助、密码重置（一次性临时密码）。四类操作均有对象/影响/后果确认；写操作以 operationId 幂等，失败保留在对话框内可安全重试。
- 全局状态覆盖：加载骨架、空数据、失败重试、提交中、完成 toast、会话失效；金额统一 ¥（整数微元入账），时间统一标注北京时间（UTC+8），状态同时用文字与颜色。

## 运行方式

```bash
npm run dev
# 浏览器打开 http://localhost:5173/admin/
# 演示凭据：admin / admin-demo（仅合成数据模式）
```

- 默认 `source=synthetic`：界面顶栏显示「演示数据 · 未连接后端」，并提供演示控制台勾选「读取持续失败 / 下一次操作失败 / 全部请求超时 / 模拟会话过期」用于验收失败、超时与会话过期流程。
- 后端就绪后：`VITE_ADMIN_API=http`（或 URL 加 `?api=http`）切换为真实 `/admin/v1` 适配层，界面代码不变。

## 前端接口需求清单（拟定路由）

类型与适配层：`src/admin/api/types.ts`、`src/admin/api/client.ts`（接口定义）、`synthetic.ts`（合成实现）、`http.ts`（真实实现）。金额均为整数微元；错误体 `{error, code, retryable}`。

| 拟定路由 | 用途 | 状态 |
| --- | --- | --- |
| POST /admin/v1/login；POST /admin/v1/logout；GET /admin/v1/session | 独立管理员会话（HttpOnly Cookie） | 待后端实现 |
| GET /admin/v1/overview | 服务/资源/队列/费用/备份/告警聚合 | 待后端实现 |
| GET /admin/v1/users（keyword/status/page）；GET /admin/v1/users/:id | 用户列表与详情（账本+设备+审计） | 待后端实现 |
| POST /admin/v1/users/:id/topup | 追加额度（amountMicro/note/operationId） | 待后端实现 |
| POST /admin/v1/users/:id/ai-pause、/ai-resume | 暂停/恢复 AI（进度保留） | 待后端实现 |
| POST /admin/v1/users/:id/devices/:deviceId/revoke | 设备撤销协助 | 待后端实现 |
| POST /admin/v1/users/:id/password-reset | 密码重置（一次性临时密码） | 待后端实现 |
| GET /admin/v1/tasks；POST /admin/v1/tasks/:id/actions | 任务列表与重试/暂停/停止 | 类型已定义，页面下批 |
| （其余见下节） | 存储统计、备份操作、部署与审计 | 下批细化 |

**待后端确认的语义**：

1. 资源指标的采样来源与字段口径（CPU/内存/磁盘当前值如何取）。
2. 队列按阶段聚合的字段名与「等待用户」的判定标准。
3. 备份「维护原因」触发时上传/AI 暂停的联动字段形状（当前以 `maintenanceReason` + 两个布尔表达）。
4. 密码重置是否允许网页签发临时密码，或仅保留受保护 CLI 兜底（当前两种都预留了 result 形状）。
5. 恢复/部署是否提供网页按钮：按方案 §9/§10，恢复前核对安全记录，网页入口待后端能力确认，本批未实现。
6. 会话时长、登录限流与 CSRF 头细节（前端 fetch 已带 `X-Operation-Id`，后续按契约补 CSRF token 传递方式）。

## 其余页面结构（下批，复用本批组件与交互）

- 任务管理：表格（账号/阶段/进度/错误码/更新时间/费用）+ 行内重试/暂停/停止；有费用操作展示费用提示；暂停保留进度、停止丢弃本轮未发布/未收下成果的确认文案按后端规则撰写。
- 存储与备份：存储占用与清理结果、备份时间/状态/到期、维护原因；恢复与部署按钮按后端能力及方案确认后再加。
- 运维与审计：部署版本、维护状态、管理操作记录与筛选（审计只读受保护）；排障仅展示错误码、状态、耗时、字节数等元数据。
