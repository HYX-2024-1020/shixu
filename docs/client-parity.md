## 共用源码与更新机制

`npm run mini:build` 用固定版本 esbuild 从桌面/shared 源码生成以下运行副本；不要直接编辑生成文件：

- `src/bucket/skins.ts`、`SkinArt.tsx` → 小程序角色预设与 7 张 PNG；既有 `public/mascot.png` 复制为同源角色图。
- `src/bucket/management.ts`、`card-copy.ts`、`card-order.ts`、`shared/relations.mjs` → 小程序同源排序、摘要、可见槽位排序和分组函数。
- `shared/bucket-engine.mjs`、`src/bucket/item-chat.ts` → v2 服务端自包含整理/对话模块，不把模型密钥放进客户端。

`npm run mini:check` 重新生成到内存并逐字节核对，检查代码、图像和 SHA256 清单；Core checks 强制执行。新增产品功能必须在 PR 的“双端影响”一节说明两端适配与关联待办，并更新上表。此规则防止遗漏评估，不能自动把任意新界面转换成另一平台代码。

安装了官方开发者工具的机器还可设置 `WECHAT_COMPILER_DIR` 为其 `resources/app.asar.unpacked/node_modules/wcc-exec` 目录后运行 `npm run mini:compile`。此命令调用实际 WXML/WXSS 编译器，并用合成资料验证编译后“世界/详情/编辑/8 款皮肤”的模板数据与事件 ID；无需开启 IDE 服务端口，但不替代完整模拟器或真机测试。CI 的页面测试还会检查所有 WXML 表达式语法，防止通用 HTML 格式化器将字符串换行后破坏编译。

微信工具导入当前任务 worktree 的 `miniprogram/`，不要覆盖旧工程、草稿或 `project.private.config.json`。CLI 自动验收需要用户自行开启开发者工具的服务端口；不能绕过安全设置。

服务端 AI 默认关闭。只有在独立服务配置同时设置 `SYNC_AI_ENABLED=true` 和 `DEEPSEEK_API_KEY` 才启用；真实调用产生费用。客户端仅在用户明确点整理/发送时创建任务，保存稳定任务 ID 后再发请求，重放不重复调用。处理中修改会留下冲突结果；服务重启中断的任务不会自动再次计费调用。`applying` 中断保留结果供核对。永久删除投递会同时清理其任务内容。

当前不包含自动任务重试、实时推送、跨设备皮肤收藏、用量汇总页或完整个人资料迁移。HTTPS/备案/类目与微信审核以实际账号和官方规则核对，未完成前不宣称正式可用。

附件的接口、容量、读取/备份/回退边界见 [原件同步说明](miniprogram-attachments.md)。开发工具服务端口已由用户开启，0.2.0 工程已实际打开且自动化接口连通；用户要求游戏期间不操作电脑后，未继续进行交互测试或权限操作。
