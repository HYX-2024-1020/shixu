## 共用源码与更新机制

`npm run mini:build` 用固定版本 esbuild 从桌面/shared 源码生成以下运行副本；不要直接编辑生成文件：

- `src/bucket/skins.ts`、`SkinArt.tsx` → 小程序角色预设与 7 张 PNG；既有 `public/mascot.png` 复制为同源角色图。
- `src/bucket/management.ts`、`card-copy.ts`、`card-order.ts`、`shared/relations.mjs` → 小程序同源排序、摘要、可见槽位排序和分组函数。
- `shared/bucket-engine.mjs`、`src/bucket/item-chat.ts` → v2 服务端自包含整理/对话模块，不把模型密钥放进客户端。

`npm run mini:check` 重新生成到内存并逐字节核对，检查代码、图像和 SHA256 清单；Core checks 强制执行。新增产品功能必须在 PR 的“双端影响”一节说明两端适配与关联待办，并更新上表。此规则防止遗漏评估，不能自动把任意新界面转换成另一平台代码。
