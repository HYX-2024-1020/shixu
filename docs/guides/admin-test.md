# 管理员测试版（iPhone 应急直连）

入口：[打开管理员测试版](https://hyx-2024-1020.github.io/shixu/admin-test/)。这是独立的浏览器本地版，不是管理员登录或生产服务。使用当前主线的桶、世界、DDL、皮肤和共享整理/日期规则；开发中的服务端分批读取、账号和任务账本没有移植进浏览器。

## 开始使用

1. Safari 打开入口，分享 → 添加到主屏幕；建议先添加，以后固定从图标打开。
2. “连接与设置”填自己的 DeepSeek API Key，读取可用模型并选择，再连接。自己的手机可选择记住；密钥不要发到聊天或仓库。
3. 粘贴一批文字通知，按需添加普通附件，点“喂！”。世界里查看原文与附件、编辑、分类/分组、搜索、星标和完成；DDL 核对截止日期/时刻，事项详情可和 AI 对话。
4. 原始文字和结果保存在当前设备。输入草稿请等“草稿已保存在此设备”后离开；保存失败时先复制文字留存。未填密钥也能保存投递，后续连接会整理等待中的内容。
5. 设置 → “备份全部本机资料”，将 ZIP 存入“文件”。恢复时选择本测试版 ZIP，检查说明后点“确认合并恢复”。

## 数据与恢复

测试版使用独立 IndexedDB 和连接配置；不会自动读取、删除或迁移原网页版、Windows 或微信资料。其他设备打开同一个网址看不到这里的资料；同一台设备有权使用当前浏览器的人可以看到内容，没有额外登录保护。同一网站来源下的程序技术上共享来源权限；独立数据库不是独立域名的安全隔离。

备份包含投递、结果、最近删除、原件、未投递草稿和用量；不包含 API Key 或连接设置。合并只添加不存在的 ID，保留当前已有记录，包括当前删除状态；当前草稿非空时保留当前草稿。恢复的待处理内容不会自动收费整理，需在世界的整理记录里手动重试。只支持本测试版格式，压缩及展开后上限均为 100MB；损坏或缺原件的备份先拒绝，不部分写入。

请定期备份。关闭网页后已提交的本地记录仍在，但清理网站数据、设备更换、无痕模式结束或存储回收可能丢失资料；Safari 与主屏幕 App 也可能使用不同空间。不保证云端容灾。

## 能力边界

- 文字、代码、TXT/MD/CSV、DOCX、XLSX、PPTX、PDF 文字层及图片/扫描页沿用浏览器读取路径；复杂布局、内嵌图表和模型转写需核对。旧 DOC/XLS/PPT 与 ZIP/RAR/7z 需要桌面环境，手机不会假装读取成功。普通浏览器的文件/页数/文字量上限仍生效。
- AI 内容直接发往 DeepSeek，并消耗该密钥余额。用量仅为此浏览器记录，费用是估算，不是整个账户账单。没有服务端预算硬限额。
- 整理或对话时保持页面打开；锁屏、后台或关闭可能中断请求，已发请求仍可能收费。原文与已完成结果保留，中断内容需要核对后重试。
- 没有跨设备同步、系统通知/闹钟、服务器分块任务、可靠断点恢复、管理后台或服务器备份。DDL 是页面展示。

## 验证范围

使用合成材料与模拟模型检查 iPhone WebKit 的文字投递、附件预览、事项对话、DDL、完成、关闭标签页后再开、独立存储及备份恢复。浏览器模拟不替代 iPhone 真机；有效个人密钥的真实费用/质量和运营商网络需要用户试用核对。部署后需核对管理员入口和其 version.json 的 revision，不能只看根页面版本。


## 主屏幕图标

管理员测试版使用 Windows 当前黄色黑字“拾”图标。`node scripts/admin-icons.mjs` 从已交付的 `public/desktop-icon.png` 生成不透明的 180/192/512px 图标，不重新绘制字形；仅此入口更新，原网页版/Windows/微信图标不变。

已经添加的 iOS 图标可能仍保留添加时的外观。先在当前主屏幕 App 内备份资料，再用 Safari 刷新测试版入口，按 [Apple 的添加说明](https://support.apple.com/en-eg/guide/iphone/iphea86e5236/ios) 添加到主屏幕并核对预览。确认新入口与资料可用前保留旧入口，不为换图标清除网站数据。实际已安装图标刷新仍需 iPhone 验收。


## 卡片滑动与排序

世界卡片正文、标题与 DDL 内容区支持直接上下滑动，手指停留后再滑动也不会拿起卡片。需要调整顺序时，长按卡片上的独立点状排序按钮再拖动；完成、星标和查看详情仍是点击操作。只在排序按钮范围内接管触摸，避免整张卡片阻止页面滚动。
