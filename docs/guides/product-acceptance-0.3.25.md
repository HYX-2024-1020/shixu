# 三端成品总体验收指南（0.3.25 候选）

本指南只定义集中体验步骤，不代表用户已验收。先以[本轮交付表](../project-continuity/product-delivery-20261111.md)确认实际安装/部署回执和明确源码版本；候选版尚未完成真实交付时不要将本页当成已安装声明。普通问题登记后留集中Bug轮，涉及资料、账号隔离和费用的问题立即报告并停止受影响操作。

1. 按交付时提供的原生更新器完成一次正常更新；不运行下载脚本、不改执行策略、不配SSH。沿用桌面「拾序」和「拾序管理控制台」两个入口。更新器应生成真实用户目录回执，代理核对后再确认安装结果。
2. 打开拾序，使用原账号。设置中默认“已有账号登录”，只填写账号和登录密码；首次注册单独切换并填写邀请码。已连接会显示当前账号，改密在“设备与密码”中填写当前密码和新密码。新资料告知已说明服务器/DeepSeek用途及备份期限，核对后确认。#102已纳入完整开发后的自行体验优化，实际效果仍由本轮明确安装版本接受总体验收。
3. 用自写的无隐私短通知和一个TXT/PDF测试文件新建投递并整理。核对来源、读取范围、结果、明确/推定截止时间和世界/DDL；编辑、完成、星标、排序，退出再打开核对保留。不要默认用历史业务资料测试。
4. 在处理过程中关闭窗口或断开网络后重连，查看同一任务和资料。需要停止/继续或收下部分时，核对费用提示和覆盖范围；已收下事项不应重复生成。上传未完成与服务器已经开始处理须分别识别。
5. 打开原控制台，用原管理员登录。总览应显示真实服务/资源/队列、费用和备份来源与时间。用户页应包含客户端同一账号的用量与设备；管理端不应提供正文、文件名、原件下载或资料导出。
6. 在合成账号上体验追加小额平台额度、暂停/恢复AI、设备撤销和账号停用/启用。全站与个人暂停独立，恢复不解除其他门禁，也不自动继续旧任务；已发调用仍可能结算。不要对当前唯一可用设备随意撤销。
7. 如需体验密码重置，用合成账号：控制台签发临时密码，原设备失效；临时密码只建立一次登录，先改为自己的新密码后才能同步资料或使用AI。不要在记录Bug时粘贴任何密码。
8. 任务页按账号、状态或错误码查找同一任务，查看阶段、有效块、累计调用/费用/活跃时限。用页面内小确认区暂停、继续/重试或停止。费用不明/资料修订/设备/时间安全门禁应阻止无证据继续，不能为了体验而解除。
9. 运维页核对源码及实际云发布、审计筛选和真实日/月预算。调低到当前消费/风险以下会阻止后续新调用；预算恢复不自动唤醒旧任务。原供应商价格校验仍独立生效。
10. 存储页核对逻辑原件、预留、空闲页、物理目录、备份和临时空间，区分逻辑额度与磁盘大小。查看最新备份及创建/到期时间；手动备份后等执行回执变为成功，不能把“已提交”当作完成。
11. 备份恢复、清理、重启及发布切换会暂时影响服务。先按代理提供的隔离合成恢复演练证据验收恢复能力；生产备份可能包含其他账号，不为了体验直接恢复整份生产备份。需要实际恢复时先核对账号和资料范围。重启或切换兼容发布前阅读页面影响，等待最终回执；失败后维护原因保留，不反复提交或尝试清费用记录。
12. 告警独立页查看发生/最近检测、对象、建议、已读及恢复历史。已读不会解除故障；审计不可删除。将普通问题按版本、入口、步骤、实际/预期、截图或错误码记录，统一交给后续Bug轮。

连接继续使用系统OpenSSH、固定主机密钥及专用受限身份，本机资源和网关经受保护隧道访问既有云主机；依赖SSH网络。本轮不是正式公网推广，也不是小程序/手机交付。阿里云实例购买、重装、开关机和续费仍在阿里云官方控制台。
