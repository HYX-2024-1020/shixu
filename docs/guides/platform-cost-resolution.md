# 管理员处理未知费用

从原“拾序管理控制台”入口打开已更新的控制台，在“告警中心”找到“有调用费用需要核对”。

1. “核对并处理费用”会检查已有可信供应商回执；证据足够时按实际费用结算并关闭告警。
2. 缺少凭据且管理员决定由平台承担时，点“由平台承担并结案”。核对账号、所列调用及精确金额，再点“确认由平台承担并结案”。取消不会记账。
3. 成功后对应告警退出待处理，历史和审计保留；用户风险预留释放，可用余额相应增加，已消费不变。用户详情会显示平台已承担、供应商账单待核对。

平台承担不代表供应商未收费，站点预算仍保留外部费用风险。后续收到可信费用，平台记成本，用户不补扣。其他人工暂停和安全门禁保持，旧任务仍由用户主动继续。若预演期间费用状态变化，按提示重新核对后再确认。

本次只更新原控制台和云端，现有Windows用户客户端0.3.29无需重装。实际版本与验证记录见[实施说明](../project-continuity/platform-cost-resolution-20261115.md)。
