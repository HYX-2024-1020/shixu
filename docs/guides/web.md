# 网页与手机浏览器

[打开当前网页版](https://hyx-2024-1020.github.io/shixu/) · [查看虚构示例](https://hyx-2024-1020.github.io/shixu/?preview=bucket)

网页由 main 构建发布，与 Windows 共用当前界面和皮肤实现。它是免安装入口，不能提供 Electron 的全部本地文件能力，也不是 Windows 安装包。

## 开始使用

在「连接与设置」填自己的 DeepSeek 密钥，输入或选择文件，点「丢进去」后到「世界」管理事项。示例空间使用独立数据库和接口配置，不读取个人资料或调用真实模型。

文字、常见图片、PDF、现代 Office 和代码的支持以界面实际读取结果为准。Windows 才提供本地旧 Office 与 RAR/7z 等处理能力；不要把文件名被接收当成正文已全部读取。

## 数据与离线

资料保存在当前浏览器中，尚未开启与 Windows 或其他设备的完整同步。换浏览器、域名或清理网站数据可能失去访问本机记录的入口，清理前先导出备份。

首次完整加载后可离线打开和保存输入；AI 需要联网，浏览器也可能暂停后台任务。若曾长期打开旧版，联网刷新使更新就绪后，再刷新一次；**无需清空网站数据**。维护者可查看站点 `version.json` 核对版本和提交。

浏览器记住的密钥保存在当前设备 localStorage，适合受保护的个人设备；Windows 使用系统加密。详见 [数据与隐私](../../PRIVACY.md)。

## iPhone 与 iPad

用 Safari 打开网页，在分享菜单中选择「添加到主屏幕」。主屏幕入口、Safari 和不同域名可能使用不同存储空间，建议固定使用同一入口并定期备份。

当前已做 WebKit 的触屏、窄窗口与横竖屏自动化检查；系统键盘、文件选择器、主屏幕安装和后台行为仍需真机验证。iOS 分享菜单直接投递文件尚未实现。微信小程序是 [另一个开发工程](../../miniprogram/README.md)，尚未公开发布。

## 旧资料空间

设置「关于这个版本」中的旧版入口用于访问以前的资料。它保留兼容实现和独立数据库，不是默认界面；不要将 `?legacy=1` 当成当前产品的展示地址。
