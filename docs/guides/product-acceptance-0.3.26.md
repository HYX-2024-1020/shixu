# 拾序0.3.26复验指南

适用于本轮Windows、原阿里云服务与原本地管理控制台。实际交付版本和用户安装状态以最终整改记录为准，不能仅凭此指南判断已经更新。

## 安装与入口

从Windows正常会话双击交付的联合更新器，等到显示更新完成。保留原桌面“拾序”和“拾序管理控制台”入口；各打开一次即可。无需输入脚本、修改执行策略或重新配置SSH。代理会核对物理路径、原生安装回执、客户端版本及控制台运行指纹。请保留安装窗口的明确错误提示；不要用开发服务器代替原入口。

## 先试三个日常流程

1. 从右上角登录；已有账号只填账号和密码。登录后应清楚显示当前账号。更多设置内可查看资料用途与原件期限、原件操作及设备/密码；同意资料用途只关联AI处理，原文中不会执行程序或宏。顶部当日已用按北京时间，个人剩余来自钱包，全站可用来自预算扣除风险，不是供应商账户余额。
2. 新建一条合成事项，编辑、完成、撤销、星标、搜索，然后删除并在最近删除恢复。彻底退出再从原入口打开，应保留编辑和恢复状态，其他被删事项不应一并恢复。星标有独立入口；排序可按截止时间、类别、创建时间或手动顺序。
3. 用“2026年11月11日晚上12点前完成合成高数作业”检查午夜：应为11月12日00:00。未写年份/月日按本次保存的录入日推定，明确时刻与推定有说明，手动覆盖会保留。DDL紧急事项更醒目，远期逐级减弱。多日期办理通知的完整时段可能集中在关键要求中，不能把一条DDL当作所有办理场次，请展开依据核对。

## 材料、失败及卡片AI

- 原文件乱码/哈希名称可显示依据内容标题或本次投递上下文的可读别名，原件身份不变。云端下载/续期/删除有等待、成功或失败回执。下载到本机缓存后，从原件面板查看或另存，不能将缓存误当系统下载文件夹。
- 分别重试原先的单条/合发、DOCX单发/通知合发、图片单发/ZIP单发/两者合发、多校区通知对照。原件仍按已授权用途处理，会产生模型费用。只有结果通过核对才作为AI整理；确实失败时应明确“原样保存”，原文/图片/文件仍能打开，错误报告编号和主动继续入口在重启后保留。
- 权限恢复不自动续旧任务。若还有费用不明或安全门禁，应先按报告核对，不要反复新建付费任务。暂停保留任务不占新投递名额，但实际在途任务仍互斥。
- 卡片对话可勾选实际核对当前卡片附件，再提问名单/表格中的具体内容。答复会显示来源范围和未读说明；同名不猜身份。最多8份附件、9万提取码点及2个图像范围；未读不能作为“不存在”的证明，复杂文档/图像仍须对照原件。
- 查询范围改为“当前账号的卡片”可询问本账号事项，范围为最近100份可访问投递中最多200项摘要，其他卡片附件不会因此自动重读。跨卡片修改先列建议，不直接生效；核对对象和变化后点击确认保存。若资料已被修改或删除，应拒绝旧建议并提示重新核对。确认保存本身不新增模型调用；重新发起AI对话可能产生费用。
- 本机资料读取失败应保留原因并显示“重新读取本机资料”，不能用空白草稿覆盖旧内容。

## 皮肤和控制台

鲸鱼与绯樱狐单击开始、再点暂停，再点从原位置继续；自然结束回到静态形象。切换皮肤/进入其他页面不会叠加旧声音。冰冰冰保留原交互。狐原声和单音轨保留；用户报告的后段额外杂音尚未复现，不能把技术音轨比对当作已修好，请在更新后按日常音量复听。

管理台“查看与处置”应将详情滚动到可见位置，显示中文阶段与安全诊断，仍不展示用户正文或下载原文件。队列解释哪些正在排队、哪些等待主动继续。告警可直达对应任务或维护页面，并记录跟进、待开发、待用户等实际处置；“标为已读”有回执，但不等于故障恢复，也不会减少未恢复角标。检测恢复后才可复核收尾；历史保留。备份用北京时间展示，内部编号按需展开；“更新存储统计”只是重新采样，不是清理。恢复备份会影响业务资料，普通复验不要对生产账号盲目执行恢复。

## 明确限制

现有连接仍依赖受保护SSH转发，不是公开业务API。小程序未进入本轮开发或手机验证。自动化通过、模型处理完成、已部署、用户原生安装和用户验收分别记录。资料未读范围、保留的历史未知故障及杂音未复现情况持续由Issue #107跟踪，不承诺零Bug。
