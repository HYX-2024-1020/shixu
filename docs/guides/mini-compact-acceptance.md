# 手机世界与 DDL 紧凑改造验收

工程：`shixu-ui-parity/miniprogram`，分支 `fix/mini-touch-motion`，Issue #50，Draft PR #47。

## 用户手动编译

请在当前微信开发工具工程点击编译，不需要重启或重连。

1. 世界：默认两列（极窄屏单列），长标题限行；分别点击完成、右上星标、底部删除，检查不会打开详情。删除需确认，最近删除可恢复；点原文与详情查看完整内容。范围下拉和收起筛选保持。
2. 世界拖动：普通上下滑动应滚动；长按标题或卡片空白后出现浮起和虚线占位，拖向另一列并松手。靠近上下边缘应自动滚动；移到右下取消区松手、触控取消或离页恢复。松手不打开详情。筛选/分组后只调整同组可见项，隐藏项位置保留；重新编译/重进后检查手动顺序保持。
3. DDL：紧凑行显示日期、时刻、标题和状态；点时间核对推定、区间和人工覆盖，点标题看完整要求。长按标题在同一日期和状态分区内调整，跨日期不换时间。检查完成、习惯打卡和删除独立；另确认鲸鱼娘仍能连续弹跳。

## 验证分层

- Node：合成页面矩形与触控事件；过滤槽位、分组、取消/离页、松手点击抑制、边缘 scroll-top、并发更新、原文/截止时间保持、存储失败原子性、重启。
- 同步：隔离本机 HTTP 服务，模拟模型，验证顺序传到桌面生成队列并重启保留；不调用真实付费模型。
- 浏览器：合成 DOM 加实际 WXSS，320/375/414px 卡片列数、紧凑高度、44px 目标和横向溢出；不代表微信原生效果。
- 官方 WXML/WXSS：离线编译和编译后模板渲染；不操作开发工具窗口。
- 微信开发工具/手机：等待用户手动编译反馈，尚未验收，不以以上结果代替。

Windows 原有交互不改，未重跑整套 Electron UI、未制作安装器。PR 保留 Draft；回滚本轮手机改造提交可保留此前已确认的原生弹跳。没有读取/迁移个人资料、上传或发布微信版本。
