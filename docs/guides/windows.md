# Windows 使用指南

## 安装与升级

从 [GitHub 最新 Release](https://github.com/HYX-2024-1020/shixu/releases/latest) 下载 Windows x64 安装器。当前安装器为 `Shixu-Setup-0.3.32.exe`，下载页提供 `SHA256SUMS.txt`。安装包未签名，Windows 可能显示无法验证发布者。

升级前先从设置导出备份，再从系统托盘选择「退出拾序」。运行安装器，沿用原安装位置，从原桌面快捷方式打开。关闭主窗口会收进托盘。安装后可直接使用，无需 Node.js。

支持软件内更新的版本可以打开「连接与设置 → 软件更新」，检查正式发行并下载。校验通过后选择「退出并安装」，拾序先保存草稿，再打开安装向导。沿用原安装位置即可保留资料和快捷方式。

## 桶、世界和 DDL

- 把文字或文件输入或拖入「桶」，确认后再提交。未连接账号服务时，可以先在本机保存资料和草稿。
- 在「世界」打开事项，查看依据与同行材料，按需编辑、拖动排序、分组、星标、完成或恢复。
- 在「世界」点击「刷新卡片」可立即尝试同步当前账号的修改，包括上传待传操作和接收手机上传的卡片。离线时已保存的修改会留在队列里。
- 在「DDL」核对截止日、时间区间和推定时刻，需要时手动修订。
- 支持常见文本、代码、Office、PDF、图片和 ZIP／RAR／7z。原件展示和提取范围按文件类型而异。

## 桌面看板

在「看板」选择视图，点击右上角「打开悬浮看板」。小条用于快速查看和勾选，窄栏用于编辑短期、长期和子事项，面板用于整理资料，DDL 用于筛选截止事项。资料面板支持拖动排序和改显示名，原件由 Windows 默认应用打开。

从标题栏拖动窗口，拖窗边或窗角调整尺寸。主程序侧栏可管理规划、最近删除和卡面配色。「悬浮窗口设置」提供置顶、位置锁定、启动恢复、字号、缩放及透明度。

## 账号与资料

未激活账号也可使用本地功能。同步和 AI 需要可用的账号服务，开通方式与额度以客户端「账号」页为准。AI 整理结果请对照原文核实。

设置可以导出和恢复资料备份。备份可能包含个人资料及原件，请保存在自己控制的位置。皮肤收藏属于本机设置。账号凭据、同步口令和备份请勿上传至公开 Issue。
