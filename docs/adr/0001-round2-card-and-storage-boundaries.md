# 第二轮卡片、小组及存储生命周期边界

状态：已确认设计，待实现。依据 [Q1—Q12](../project-continuity/acceptance-round2-grill-20261113.md)。

失败投递不长期充当无法管理的错误面板，而生成待处置默认卡；保留、删除、重试互斥，保留后进入普通卡片生命周期。这增加明确的状态转换责任，但避免失败材料游离于计数、编辑、删除和恢复之外。重试不能复制卡片或重复计算已结算处理，安全门禁不因此解除。

类型、小组与合并分别表达内容性质、用户主题组织及内容整合；小组持久化且允许一卡多组。代价是必须显式维护关系及删除/恢复语义，收益是用户规划不再受模型临时标签或固定类型导航支配。合并保留各事项独立日期/状态与附件来源，源卡退出正常列表且可撤销；撤销不得覆盖后续编辑。

原件期限与卡片期限分离。安全释放仅处理符合保留规则且不损害有效资料的内容；不足时限制新上传，不擅自删除仍使用的原件或最后可用备份。该选择牺牲临界空间下继续上传的可用性，换取资料完整性与可解释性；不能用通用清理按钮隐式销毁业务资料。
