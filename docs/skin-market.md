# 桶的皮肤市场

点击右上角「皮肤市场」或首页角色下方「换个伙伴」打开。先点皮肤卡片预览，再点「就选这个朋友」应用。首页和「世界」页跟随同一选择。

## 预设与互动

预设 8 个伙伴：小鲸鱼、摸鱼小橘、发芽计划、罐头同学、幽幽、迟到小兔、小小宇宙、布丁吨吨。小鲸鱼保留原有图片和笑声，其余使用可离线显示的原生 SVG 插画。

点击角色触发专属台词与蹦跳、摇摆、转圈或漂浮动作；再次点击停止，互动也会自动结束。拖入内容时显示接收台词，成功投递和整理时显示进食台词与动作。市场内「试着喂一口」仅演示互动，不提交内容或调用模型。系统开启减少动态效果时关闭这些动画。

## 自定义

「自己做一个」支持上传 PNG、JPG、WebP（最大 8 MB），设置名称、介绍、舞台颜色、动作以及平时、被戳到、进食三种台词。左侧实时预览，保存后进入「我的收藏」，可应用、编辑、删除。删除正在使用的自定义皮肤后恢复小鲸鱼。

图片在本机缩放至最长边 480 像素并重新编码，保留透明背景。最多 8 个自定义皮肤，收藏序列化总长度最多 200 万字符；浏览器空间不足或禁用存储时显示错误，保留当前选择。

这是预设选择与个人收藏市场。收藏和使用中的皮肤仅保存在当前设备、当前浏览器，不上传公共市场，不随事项同步，也不包含在现有事项备份中。清理网站数据会清除这些收藏。示例空间与个人空间使用独立存储键。

## 开发与验证

- `src/bucket/skins.ts`：预设、互动配置、图片处理和本机存储校验；添加预设时在此登记。
- `src/bucket/SkinArt.tsx`：角色插画；新增 SVG 形象在此扩展。
- `src/bucket/SkinMascot.tsx`：角色的交互与音频生命周期。
- `src/bucket/SkinMarket.tsx`、`skins.css`：市场、编辑器及响应式布局。
- `src/bucket/skins.test.ts`：存储恢复、格式校验和空间错误。
- `e2e/skins.spec.ts`：桌面及手机的试用、应用、上传、编辑、删除、刷新恢复、草稿保护与空间隔离。

运行 `npm test`、`npm run build`、`npx playwright test e2e/skins.spec.ts --project=desktop --project=mobile`。桌面版使用构建后运行 `node scripts/desktop-smoke.mjs` 验证兼容性。

验证备注（2026-10-24）：原有 `e2e/bucket.spec.ts` 与 `e2e/relations.spec.ts` 仍引用旧的 `.bucket-item`、`.packet-ready` 等界面元素，尚未适配现有「桶 / 世界」布局；完整网页套件不能作为通过记录。这些选择器在本次修改前的 HEAD 中也已不存在。本次新功能用例独立验证，当前桌面烟测另覆盖草稿恢复、分类、编辑、完成、星标和删除恢复。

本次通过：55 项单元测试、8 项桌面/手机皮肤流程、正式构建，以及 `desktop-smoke.mjs` 和 `desktop-management-smoke.mjs`。皮肤流程包括 320 像素窄屏、全部预设、减少动态效果与真实本机投递反馈。全量旧网页套件另有 18 项用例因上述界面适配问题失败，未修改这些旧用例。
