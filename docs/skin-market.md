# 桶的皮肤市场

点击右上角「皮肤市场」或首页角色下方「换个伙伴」打开。点击皮肤卡片立即应用，无需额外确认。首页和「世界」页跟随同一选择。

## 预设与互动

双端预设只保留小鲸鱼（鲸鱼娘）和《冰冰冰》。小鲸鱼保留原图与笑声；冰冰冰使用用户提供的三块冰图片，经抠图生成透明 PNG。旧版猫、芽、机器人、幽灵、兔、星球、布丁预设移除，之前选择这些预设的设备回退小鲸鱼；个人自定义收藏保留。

使用冰冰冰后，可在首页角色旁直接选择「声音一」「声音二」，分别取自用户提供的两段不同声调录屏。每份仅截取一声完整的「冰冰冰」，点击从头播放一遍，不循环、不叠音；声音一长 1.00 秒，声音二长 0.73 秒（含短尾音）。切换声音立即停止旧播放；关闭市场、离开首页及组件卸载会清理桌面播放，小程序切换预览、应用或切入后台也会停止播放。声音选择保存在当前设备，重启仍有效，不随事项同步。

冰冰冰只显示透明抠图，不附加气泡、星星、阴影或动作；点击只播放音效。鲸鱼娘与自定义角色保留原有专属台词和动作，再次点击从头播放。拖入内容时显示接收台词，成功投递和整理时显示进食台词与动作。市场内「试着喂一口」仅演示互动，不提交内容或调用模型。

## 自定义

「自己做一个」支持上传 PNG、JPG、WebP（最大 8 MB），设置名称、介绍、舞台颜色、动作以及平时、被戳到、进食三种台词。左侧实时预览，保存后进入「我的收藏」，可应用、编辑、删除。删除正在使用的自定义皮肤后恢复小鲸鱼。

图片在本机缩放至最长边 480 像素并重新编码，保留透明背景。最多 8 个自定义皮肤，收藏序列化总长度最多 200 万字符；浏览器空间不足或禁用存储时显示错误，保留当前选择。

这是预设选择与个人收藏市场。收藏和使用中的皮肤仅保存在当前设备、当前浏览器，不上传公共市场，不随事项同步，也不包含在现有事项备份中。清理网站数据会清除这些收藏。示例空间与个人空间使用独立存储键。

## 开发与验证

- `src/bucket/skins.ts`：预设、互动配置、图片处理和本机存储校验；添加预设时在此登记。
- `src/bucket/SkinArt.tsx`：角色插画；预设使用桌面图片，小程序由构建脚本逐字节复制。
- `src/bucket/SkinMascot.tsx`：角色的交互与音频生命周期。
- `src/bucket/SkinMarket.tsx`、`skins.css`：市场、编辑器及响应式布局。
- `src/bucket/skins.test.ts`：存储恢复、格式校验和空间错误。
- `e2e/skins.spec.ts`：桌面及手机的试用、应用、上传、编辑、删除、刷新恢复、草稿保护与空间隔离。

运行 `npm test`、`npm run build`、`npx playwright test e2e/skins.spec.ts --project=desktop --project=mobile`。桌面版使用构建后运行 `node scripts/desktop-smoke.mjs` 验证兼容性。

当前验证：57 项单元测试、32 项 Chromium/WebKit 浏览器回归、十二套实际 Windows 桌面回归；皮肤专项覆盖本机进程重启、自定义图片、草稿保护与删除恢复。实际结果见 [0.3.8 发布说明](releases/windows-0.3.8.md)和对应 PR/Release 报告。

## Windows 0.3.8

皮肤市场纳入最新桌面发行，保留 0.3.7 的卡片动画、长按排序和本次投喂。新增 scripts/desktop-skins-smoke.mjs，使用独立 profile 和合成图片验证真实 Electron 的预设/自定义、进程重启、草稿保护及删除恢复默认形象；已接入桌面 CI，也可通过 SHIXU_PACKAGED_EXE 验证实际发行 exe。后续从最新 main 开发；本机收藏仍不跨设备同步或包含在事项备份中。


0.3.20 修复了旧音效文件虽可解码却完全静音的问题：先截取并重置片段时间戳，再执行边缘淡入淡出。两种声音的解码 RMS 分别约 0.055 和 0.052；浏览器与实际 Electron 回归均检查非静音信号，不能仅以时长和 play 调用成功判定音效可用。微信播放设置 obeyMuteSwitch=false，播放错误显示可见提示。
