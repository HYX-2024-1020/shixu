## 连接与资料边界

Windows 开发版本「连接与设置 → 云同步」填写同一 HTTPS 服务地址和同步访问口令。它与 DeepSeek 模型密钥分开，访问口令只用于签发设备 token，不保存口令；token 在主进程中由 Windows safeStorage 加密保存。网络请求在主进程发送，不放宽浏览器来源检查。小程序沿用原生连接页，设备 token 保存在微信项目本地存储，AppSecret 不进入客户端。

连接后进入独立云端空间；原本机记录、草稿与原件不自动上传。每个服务地址分别保存草稿、用量、持久队列、冲突和原件缓存。切回本机后未同步操作仍保留，再连接同一服务继续；旧页面的空间标记不能写入新空间。云端空间暂不提供本机 ZIP 备份和按本机 30 天规则自动清理，服务器一致性备份独立执行。

桌面复用小程序同步队列，由 mini:build 生成 desktop/generated/sync-client.cjs，mini:check 检查副本。队列落盘后才确认保存；断网/授权失效/服务 epoch 变化不清队列。冲突可以采用云端或另存本机副本；旧界面提交时检查记录版本，防止轮询后用旧内容覆盖云端。不同设备的待整理投递不会仅因被拉取就自动触发本机模型，桌面新投递沿用原整理行为；对收到的投递显式重试才接管整理。

原件按 SHA256 校验并保存至隔离空间，先保存本机字节再排队。首次含附件的投递用稳定、可重放的 scaffold 操作建立记录，再上传原件、提交引用；响应丢失后可安全重试。继承服务端每文件 10 MiB、每投递 20 个原件限制。下载核对大小与 SHA256；成功同步后仅清理队列、冲突、记录与草稿均不再引用的缓存。手机端仍只有 UTF-8 原件读取，二进制附件的 AI 阅读不在本轮范围。

## 真机与正式使用尚缺的条件

当前服务器没有配置域名、TLS 证书或反向代理，不能把 127.0.0.1:18788 填到手机上。开发工具临时工程仅为本机 SSH 验证关闭域名校验，仓库 project.config.json 仍保持 urlCheck=true。

下一步由用户确认或注册其名下域名；完成域名实名认证、解析与适用的备案流程后，配置 HTTPS 反向代理和微信后台 request/upload/download 域名，再做 iPhone 真机、授权过期、附件和重连验收。域名和微信账号操作不能由当前 SSH 权限代替；没有把模拟器成功写成正式发布。

微信网络规则参考 [官方网络说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)。本轮不发布/替换已安装 Windows，不上传或提审小程序，不自动迁移个人资料。合并须先核对 PR #18 的依赖及本 PR CI；附件资料已经使用后不能让旧纯文字代码直接指向新数据库。回滚先保留当前数据库一致性备份，恢复在隔离副本验证后再处理 epoch 和设备队列。
