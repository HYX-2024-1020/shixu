# 0.3.10：截止时刻恢复与推定

关联 [Issue #29](https://github.com/HYX-2024-1020/shixu/issues/29)。用户反馈明确说明的时刻仍显示未知，并要求时刻缺失时也要安排一个时间。此要求取代 DDL 初版将不明时刻留空的规则。

## 修复

- 模型的日期依据只截取“明天”时，从绑定证据、对应来源及已保存事项对话恢复时刻。中文分钟、半点、一刻/三刻、全角钟点、AM/PM 均支持；晚间十二点和 24:00 正确跨日。日期仍待确认的卡片也优先保留原文明确的时刻，不强行猜日期。
- 旧卡片无需重新投递或付费重跑模型，显示时恢复空时刻；保留原文和明确的人工覆盖，不直接批量改写个人数据库。
- 没有时刻时，上午按 09:00、中午 12:00、下午 15:00、傍晚 18:00、晚上 20:00；只有日期按 23:59。裸钟点按常用日间时段推定，核对区保留 `timeInferred` 和 `timeReason`，可手动覆盖。
- Windows 与小程序不再显示未知时刻文案，旧的“未填入具体时刻”提示由安排依据取代。日期冲突等其他不确定信息继续保留。
- 事项对话中只修改时刻时沿用该卡片已有截止日期；日期已明确但 anchor 漏掉时刻时，也从本轮指令恢复。
