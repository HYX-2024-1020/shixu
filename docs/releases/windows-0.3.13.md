关联 [Issue #36](https://github.com/HYX-2024-1020/shixu/issues/36)；功能修复已在 [PR #35](https://github.com/HYX-2024-1020/shixu/pull/35) 合入。此前安装版仍是 0.3.12，未包含该修复；代码合入没有自动更新本机客户端。
