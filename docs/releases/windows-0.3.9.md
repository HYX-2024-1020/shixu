## 发布与回退边界

此记录是本机交付，不表示微信手机、体验版、正式版或公开下载已更新。公开安装器仍以 Release 为准；手机需独立上传、审核与真机验收，云端模型服务不会随本机工程更新。

安装器不进入 Git。源码回退通过 PR；旧 0.3.8 公开安装器保留。回退不得删除个人资料或微信旧工程。以后本机更新必须核对实际安装版本、当前工程与可见入口，不能用 PR 合入替代这一步。
