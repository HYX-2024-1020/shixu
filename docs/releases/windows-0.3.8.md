# Windows 0.3.8：皮肤市场进入桌面版

关联 Issue #13。用户要求先将现有皮肤市场加入最新软件，再持续打磨。此版本从整合后的 main 开发，保留 0.3.7 的本次投喂结果、原位开合、长按排序、编辑/对话/附件预览。

## 功能

右上角「皮肤市场」或角色下方「换个伙伴」打开；8 款预设各有台词与动作。可以上传自定义图片、设置台词与动作、编辑和删除；选择同时用于桶和世界，重启后保留。

收藏保存在当前桌面 profile，本次不改变事项存储格式；收藏仍不随事项备份或跨设备同步。小程序、云端部署、附件同步和微信登录不属于此发行。原有第三方素材授权待办继续由 Issue #3 跟踪。

## 发行验收

- 57 项前端/引擎/皮肤单测、13 项桌面数据/文件检查、5 项 PR 门禁检查通过。

## 安装与回退

退出托盘中的拾序后运行 Shixu-Setup-0.3.8.exe，沿用现有安装目录。不要强杀运行中的应用；旧版退出会先保存草稿。v0.3.7 标签与安装包保留供追溯；源码回退通过新的 fix/ 分支与 PR，不重写 main 或发布标签。
