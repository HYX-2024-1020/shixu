## 无声根因与修复

两份旧 MP3 解码后 peak/RMS 均为零，虽然时长和格式正确。旧处理在输出截取前应用淡出，片段开始时已被静音。修正为先重置录屏音轨时间戳、截取、重置片段时间戳，再做边缘淡入淡出。声音一1.00秒，RMS约0.05496；声音二0.73秒，RMS约0.05221。来源和使用范围见 [素材说明](../../THIRD_PARTY_NOTICES.md)。增加浏览器和实际 Electron 的非静音 PCM 检测，并验证两音色播放至自然结束。微信使用同一MP3副本、obeyMuteSwitch=false，错误有可见提示。
