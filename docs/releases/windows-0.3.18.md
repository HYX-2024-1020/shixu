# Windows 0.3.18：纯色动漫卡片与卡面信息

关联 Issue #57，任务分支 `feat/cel-card-system`。用户授权双端改版、本地微信工程更新和 Windows 覆盖安装。没有公开 Release、微信上传审核或服务器部署。

## 变更

沿用 0.3.17 的粗框贴纸结构，以黄紫/墨黑为主，纯色色块、细亮边与双层硬阴影替代柔和装饰；大部分标题水平。世界、DDL、事项详情、手机折叠/展开同步适配。保留分组/星标/置顶、完整日期和时刻/区间、倒计时和核对、完成/撤销/习惯、编辑/删除/恢复、原文/附件预览与 AI。卡面重新展示附件格式和文件名，隐藏软删除文件；不插入假示例或重写用户记录。

小程序整张卡片（包括空白与操作区）可长按排序；只在根节点绑定一次触摸监听，短点依旧走独立操作。拖动松手后的合成点击有保护，既有 WXS 跟手、滚屏、取消、同组/日期限制、批量保存和重启持久化保持。DDL 正文点击切换摘要，详情和时间核对独立。

## 验证

核心 91 项、桌面底层 18 项（含页面重载等待回归）、完整浏览器 60 项、17 套 Electron UI 通过。新增手机附件/长按回归后小程序 75 项通过；实际 WXML 卡片的 320/375/414px 布局 12 项通过。Windows 贴纸回归增加分组、日期、多附件/软删除、材料入口、无渐变及 720/1360/1920px 不越界，使用隔离合成资料。官方 WXML/WXSS/WXS 编译及实际模板数据/事件检查通过。最终安装与预览工程证据在下方记录。

微信原生点击/手势、键盘和原生文件权限及手机真机尚未验收，不能用浏览器/Node/编译通过替代（继续跟踪 #46）。未读取个人 profile 内容，未调用真实收费模型。远端首轮 Windows 账号激活验收暴露页面重载竞态：等待脚本在旧执行上下文销毁时中断。等待器现仅对该瞬态重试，真实 IPC/页面关闭错误仍上抛，增加两项回归并重跑激活检查；该修正不改变产品构建。最新远端 CI 与合并以本任务 PR 为准。
