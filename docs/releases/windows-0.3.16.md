# Windows 0.3.16：恢复 DDL 剩余天数

分支 `fix/ddl-countdown`，关联 [PR #51](https://github.com/HYX-2024-1020/shixu/pull/51)。用户明确要求更新本机 Windows 版，本轮不切换或发布微信客户端，不部署服务或公开发布 GitHub Release。

## 功能

恢复原稿 DDL 时间栏醒目的「还剩 N 天」，同时保留绝对日期、截止时刻、区间两端与核对入口。按查看时的本地日历日计算，跨月、跨年、闰日不按剩余 24 小时块取整；区间按结束日计算。今天截止、今天已逾期、已逾期 N 天、已完成和日期待确认分别显示，页面定时、聚焦和切回 DDL 时刷新。保留后来确认的时刻恢复/推定规则，不恢复旧稿「具体时刻未知」。
