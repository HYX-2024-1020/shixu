## 功能

双端内置皮肤仅保留鲸鱼娘与冰冰冰。用户冰块图片已抠透明背景；两段用户录屏各截取一声完整「冰冰冰」（1.00 / 0.73 秒，含短尾音）。声音一/声音二可切换并保存，每次点击从头播放一遍，不循环、不叠音。旧预设选择回退鲸鱼娘，个人自定义收藏保留。来源和使用范围见 [素材说明](../../THIRD_PARTY_NOTICES.md)。
