# 0.3.12：自然时间、时间段和导航避让

关联 [Issue #32](https://github.com/HYX-2024-1020/shixu/issues/32)。Windows 和微信小程序共同更新。

- 时间按原录入日解析。无年份月日取最近对应日期，单独日号取本月尚未来临的该日，否则顺延到下一个有效月份；明确的本月、去年等限定保留。跨月、跨年、月底、几天后和中文数字日期支持推算，核对区说明依据。
- 日期或时刻区间保留绝对 startDate/startTime 与结束 date/time，统一显示 YYYY-MM-DD HH:mm → YYYY-MM-DD HH:mm。日期范围缺少时刻时使用 00:00 至 23:59；逾期看结束端点，正在持续的范围也纳入时间窗。保留来源原文；旧待确认卡片可从绑定证据恢复，存在冲突的不自动选择。
- 无法解析的手动补充进入待确认。人工清除日期后不再从原文自动恢复。模型整理、事项对话、世界和 DDL 共用规则。
- 小程序时间窗使用与 Windows 一致的方形描边手柄、硬阴影和黄底档位；原生滑动仍接收手势。底部导航与内容滚动视口分开，两端预留安全区；桌面拖动排序自动滚屏和工作区位置恢复同步调整。

验证使用合成材料和隔离资料，具体结果及本机安装器 SHA-256 记录在 PR。公开 Release、云部署、微信上传发布与手机真机独立验收；本轮不调用真实付费模型。源码回滚使用 revert，保留个人资料。
