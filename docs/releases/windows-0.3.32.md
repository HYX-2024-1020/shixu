# 拾序 Windows 0.3.32

- 在「世界」点击「刷新卡片」，可立即上传当前账号的待同步修改、拉取新变化并更新卡片列表。
- 「连接与设置 → 软件更新」可检查并下载 GitHub 正式发行。校验通过并确认安装后，拾序保存草稿、退出并打开安装向导。
- 「管理小组与类型」移到小组筛选旁，为顶行的星标筛选腾出空间。

从 0.3.31 升级时，请从发行页下载安装器。升级前备份资料并从托盘退出，在安装向导中沿用原位置。安装器为 Windows x64，发行页提供 SHA-256 校验值。

需要回退时，可从旧版发行页下载 0.3.31 安装器。先备份当前资料，并保留升级前的备份。
