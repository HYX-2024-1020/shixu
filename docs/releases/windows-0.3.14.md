# 0.3.14：邀请码账号版 Windows 本机更新

关联 [Issue #40](https://github.com/HYX-2024-1020/shixu/issues/40)。从最新 main 16e7f9a 构建，分支 chore/windows-accounts-release。本轮仅更新版本与交付记录，产品功能由 PR #41/#42 承接，保留已有桶、世界、DDL、皮肤和动画。

## 实际安装

用户从托盘正常退出0.3.13后，先在本机受保护的.private/before-0.3.14完整备份原profile，再静默覆盖安装，退出码0；实际安装exe文件版本0.3.14，与打包exe哈希一致。备份与检查只进行文件复制和哈希比较，不解析个人资料、旧密钥或自动上云。

- 安装器：Shixu-Setup-0.3.14.exe，144190006字节。
- 安装器SHA-256：93adb3af86d5a3d216b2d4ead6f8b706bea6d1102a46f388b40d942558a1b276。
- 实际exe/打包exe SHA-256：85ab4b9d1746d0335ce7adfba8aa95e7b9af8977b5260eb865be4013ce0bce4a。
- 个人workspace/state.json安装前后哈希不变，沿用原资料目录；未迁入任何账号。

## 可用范围

设置改为邀请码激活，不再要求服务器地址、模型Key或模型选择。账号未激活时仍可保存本地投递、查看已有资料并手动管理事项；AI只走统一服务端，旧本机Key不读取、不迁移。激活后打开独立账号空间，旧本机资料不会自动上传。

正式安装版固定https://sync.shixunote.top，忽略开发服务地址覆盖；备案期间DNS/HTTPS与微信域名尚未完成，因此本次安装并不等于公网激活可用。服务器AI继续关闭；未为安装验收调用付费模型。图片/Office/PDF原件可保留和预览，但当前账号服务端只读取UTF-8文字原件，不宣称旧版本机OCR能力已经迁到服务端。
