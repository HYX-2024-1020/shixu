# 拾序 Windows 0.3.31

这是 Windows x64 客户端发行。安装包与校验值见 [GitHub Releases](https://github.com/HYX-2024-1020/shixu/releases/latest)，操作见 [Windows 使用指南](../guides/windows.md)。[拾序官网](https://www.shixunote.top/)提供产品介绍和隐私说明。

## 相比上次公开发行

- 桌面看板包含小条、窄栏、资料面板与独立 DDL。多份规划可分别保存，支持短期事项、长期父计划及子事项、最近删除恢复。
- 悬浮窗支持置顶、拖动与调整尺寸，显示缩放、字号、透明度及配色可调。资料卡可排序、改显示名并用系统默认应用打开原件。
- 「世界」支持完善的卡片操作、原件预览和拖动排序。DDL 支持日期区间、时刻推定及手动覆盖。皮肤市场增加角色与音画改进。
- 可备份本机资料。账号空间的同步、文件与 AI 服务按开通条件使用。

本次发布范围为 Windows 客户端。网页、小程序、管理台和服务器分别管理版本与部署。

## 安装与回退

全新安装可直接在本机使用。覆盖安装前先备份并从托盘退出旧版，沿用原安装目录。安装器未签名，下载后可用 `SHA256SUMS.txt` 核对完整性。回退前先保留当前备份及原目录。新版本写入的资料可能无法被旧版本读取，回退时使用升级前的备份。
