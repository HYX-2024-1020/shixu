## 真实缺口与复用

最小回归先证明：保存租户快照→永久删除投递→恢复旧快照，原实现会重新返回未删除投递。`sync_records`墓碑、`original_files`状态/期限和`original_trash`回收期限都在可回退租户库中。账号检查点只保护账号权威，不能保护这些表。

复用ea43dcb/9e326d7的独立账本、同步写者授权、跨库意图/决定模式及严格schema检查；不把账号投影搬来。沿用原件manifest/500MiB/temporary/30+7、投递7天、事项30天、共享blob清理，以及`ReadingRootSafety`调用/时间水位、费用/unknown、影子版本和退役空库封锁。

## 行为与恢复范围

显式`reading-runtime`开启`tenantSafety`。每个租户保存独立生命周期链：投递ID/删除时间/墓碑，原件ID/哈希/大小/模式/状态/版本/期限，回收期限和epoch。记录不含正文、文件名、原件字节、结果或凭据。普通正文/卡片编辑不改变生命周期投影时，不追加检查点。

租户写事务核对本地检查点与独立头，执行原操作，在独立账本先提交不可变意图；本地以FULL同步提交资料和双标记，再追加独立决定。决定以零金额系统事件进入原账本前缀证明，不改变钱包、用户消费序号或根累计。独立写失败后关闭租户入口、同步及原件读取，不能继续服务未决资料。

| 情况 | 处理 |
| --- | --- |
| 意图提交、租户未提交 | 本地token和完整投影匹配意图的原状态，追加aborted；重启不重复决定 |
| 租户提交、独立决定未提交 | 新token和投影匹配意图，追加committed |
| 已提交祖先快照、生命周期变化可安全收紧 | 重放已确认的投递删除/永久删除、原件删除/到期清理和回收期限；清除原件逻辑引用，保留其他有效共享引用；事务更换epoch，旧离线操作须完整重同步 |
| 重放过程中进程退出 | 同一原/新检查点协议核对中断位置；未提交重放先中止再重放，已提交重放补决定；重复打开不新增重复决定 |
| 缺失/不匹配检查点、链不连续、独立记录回退、内容集合不同 | 保持关闭，不凭旧资料建立新权威 |
| 旧快照需要重建新增内容、人工恢复或延长的续期 | 保持关闭；本批不猜测缺失正文或重建正向操作，需后续受信恢复流程 |
| 现有租户没有独立基线 | `TENANT_SAFETY_BASELINE_REQUIRED`；仅空租户且无既往根记录可初始化。没有执行真实旧资料导入 |

重放只接受本账号独立链中可核对的已提交祖先，不是任意旧库合并。普通人工恢复和原件续期仍正常提交；确认过的期限不能由旧库延后。已清原件仍仅能临时核验供读取，不能下载或重新保留；共享blob不能恢复已清逻辑引用。temporary正文不进入持久库。原件到期时若输入锁未释放，沿用原任务保护，读取仍检查清理期限，不通过移除锁强行通过验证。
