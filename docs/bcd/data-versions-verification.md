# 全局写入屏障与影子集合切换开发验证

2026-11-01，#73 / #69，PR #74保持Draft；继续B/C/D实施，未组织最终独立联合验收。

## 实现

新增server/data-versions.mjs及data-migration.mjs。运行服务持有唯一runtime写入登记，管理CLI持有共享writer登记，离线迁移/已有停止备份入口持有排他maintenance意图。创建登记后重查维护意图，维护先写意图再核对所有写入登记；跨进程互斥，不凭时间/PID猜测抢占。释放也校验随机token归属。服务quiesce沿既有有限排空、unknown/活跃时间及迟到写屏障关闭全部连接后才释放登记；启动失败关闭已建资源，无法确认关闭时保留登记。

这约束本版本服务、管理CLI及停止备份入口；升级前尚不认识登记的旧程序仍须由宿主实际停止，不把文件登记当成终止旧进程的证明。异常退出的残留登记失败关闭，受信宿主终止证据及恢复接线仍需继续。没有生产停服或进程清理。

prepareShadowVersion仅在排他维护下，从当前选定资料集合复制注册表和全部现存租户；所有账号（含暂无租户资料的身份）进入清单，拒绝孤儿租户、链接、未知成员和未关闭WAL/SHM。先核对完整性/外键和至少两倍数据库总量的剩余空间，逐库迁移、关闭、文件与父目录fsync，再写完整manifest。记录每库hash/字节数/schema/组件历史、完整账号及租户集合；失败保留不可启动的影子目录，不改当前指针。

createRuntimeMigrator调用实际AccountRegistry/AccountsV4、SyncStore、附件、旧队列、OriginalStore和ReadingTasks，初始化全部已存在功能结构；拒绝未版本化目标或没有完整写入保护的表。旧任务/原件/付费保护沿既有契约，queued任务在离线关闭后中断，不能迁移后自动消费。迁移器没有真实provider/reader/密钥，不调度、不发额度；不把旧输出当已验证块。宿主可选择是否启用已有账号凭据迁移。

当前独立账本同时承载费用与根安全结构，位于资料版本目录之外，不复制进影子集合。manifest绑定reading_events和reading_safe_events的序号与完整前缀hash，逐行累计，不把全事件历史读入数组；后续追加允许，回退或改写前缀拒绝。它尚不等于全部账号/删除/撤销独立安全事件重放。

activateDataVersion再次核对目标全部hash/结构/权限门禁及独立前缀，校验预期旧版本，原子rename替换同文件系统指针；追加不可覆盖的激活收据。旧指针回退、旧版本再次激活和未提交指针拒绝启动。rename前后故障保持维护；completeDataActivation仅在排他维护下复核未打开的全集后补齐收据，不能从混合文件猜测恢复。服务/管理/停止备份统一解析指针，备份只复制当前集合。

切换前给旧根注册表加accounts-core3写入门禁及data_version_required标记：旧二进制拒绝未来版本，当前程序直接打开旧根也拒绝，防止忽略指针继续写旧资料。账本不跟随指针回退；选定集合的运行服务必须提供同一真实独立账本路径，内存账本和v3降级运行拒绝。正常运行后资料文件会变化，启动检查完整manifest/成员、激活链和独立账本前缀，实际组件构造器继续验证当前schema；不能把初始文件hash误用为永远不变的活动资料hash。

SQLite检查在确认没有WAL/SHM且停止的副本上使用immutable只读URI，避免普通只读WAL连接自己留下sidecar；只对已停资料使用，活跃独立账本仍走正常只读快照。依据[SQLite WAL](https://www.sqlite.org/wal.html)、[immutable URI语义](https://www.sqlite.org/uri.html)及[Node SQLite](https://nodejs.org/download/release/v24.20.0/docs/api/sqlite.html)。Windows无法通过相同API刷目录，开发证据只覆盖原子替换/故障门禁；Linux执行文件及目录fsync。没有声称实际断电/硬件持久性验收。

## 剩余与回退

这是BCD迁移底层与合成开发验证，不是正式资料迁移、E运维验收或10人F负载/部署。仍需：完整独立账号/删除/撤销安全重放、真实账单/宿主证据接线、异常残留登记的受信恢复、旧根/历史影子资料的到期清理与备份7天轮换执行器、其他材料/流式能力。完整最终独立联合验收另开一轮执行。

不能把老资料目录直接覆盖到当前账本或删除登记/指针/收据来解锁。已激活且有新写入的版本不支持退回旧资料指针；采用保留当前账本/安全前缀和版本门禁的前向修复。旧根和未完成影子需隔离处理，不能称为永久备份或自动重启来源。
