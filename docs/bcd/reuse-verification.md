# 跨输入修订有效块复用联合增量

2026-10-28实现、2026-10-29接续验收（北京时间）。Refs #73 / #69，继续同一 Draft #74，基线bf09e33。B/C/D整体未完成。

## 实现前决策

只在同账号、同投递内复用仍存在的有效付费块，重新取得当前原字节、核对hash并经过隔离读取；绝不从结果引用恢复原件。按原件边界分模型窗口，避免仅修改输入文字就让附件窗口整体漂移。小原件可能各占一次调用，增加调用开销；仍在既有预算/根时限/24调用检查点内，不能靠复用跳过unknown或人工核对门禁。

复用证书仅存材料/窗口hash、来源范围、模型/读取/规范化/提示词/结果schema版本、输出上限与录入日的摘要，以及原付费调用关联。候选必须来自同投递仍保留的原块，账本证明同账号同原任务/块且settled，有限结果摘要一致，并以当前来源重验每条引用。不同投递、旧证书缺失、输入/格式/位置/录入日/模型变化不猜测复用。变动的ZIP任一原字节都会使整包旧块失效，本批不做包内语义等价推断。

目标任务原子保存新块/来源/复用收据，费用不重复结算、root调用不增加，复制的块不冒充新增根进度；重启不得重复算进度。清除删除目标证书，不能从已清除块重新导入。完整提取正文只在短期内存，证书无全文。

两端显示“复用N个已付费块”，本任务新调用与根累计分别保留；停止/补传/删除墓碑/设备撤销等门禁不变。此增量不等于语义合并、供应商安全重试、审计解除或正式迁移。

## 验证与剩余边界

固定长混合ZIP取自既有7172/579143字节样本，复用其独立全文golden，不新增私人材料。先复现：只加投递文字后总调用从2增至5，未变ZIP也重算；实现后旧2块复用、仅新增1次文字调用。原件/文字各自进入真实隔离读取，核对全部文字SHA-256与尾部，发布保留旧事项/引用和新增文字事项；任务证书不含全文。

按录入日、模型/输出上限、原件hash、读取器版本、缺失旧证书、purge、损坏证书、无效引用、缺失调用分别验证不复用；不同投递不能共享块，缺失原件不能由结果替代。unknown费用和根计时核对继续拦截，复用收据失败时块/范围整体回滚，不新增费用；恢复后可复制，重启不把复用块算新进度。审查补录入日进入inputRevision，改变录入日的旧任务continue返回INPUT_CHANGED，避免相对日期复用。

独立Linux目录 `/opt/shixu-bcd-test-20261028-reuse`，既有最小Node24.20.0 runtime，未安装宿主包/修改生产。5次“初次整理→补文字→重新读取→复用→发布”定向测量：长混合ZIP每次初始2模拟调用，新任务1调用、复用2块，根累计3调用/3有效进度，60微元合成消费。当前修订全链（含两个隔离读取和模拟模型）P50/P95约866/883ms、worker峰值81068KiB，见[固定基准](evidence/reuse-benchmark.json)。模拟模型没有实际网络延迟，修订链比初次多一次文字隔离读取，不能据此声称真实模型提速或生产SLO；节省的是可证明的2次模型调用，不推算真实金额。

普通UID通过受保护broker完成temporary过期及deleted同hash临时核验后的双端修订：各重读当前原件、复用2块、仅新调1次文字，旧墓碑/期限/额度不恢复，根累计包含此前停止的已发送调用共4次。单次完整多阶段链约4.04/4.11秒，不是P95；见[过期链](evidence/reuse-expired-loop.json)、[墓碑链](evidence/reuse-reverify-loop.json)，UID越权及probe注入均拒绝。

测试修正：跨投递夹具最初复制了服务端只读覆盖字段，被接口正确拒绝，改为只提交合法输入；源码Electron初次用了不存在的loadPackets IPC，改为既有packets接口。基准初次直接返回broker封装而非材料＋timing，改正适配后执行正式5次样本，未提高限额或修改golden迎合结果。已有通过检查不重复跑全套；仅对新增测试/录入日修正补直接相关验证。
