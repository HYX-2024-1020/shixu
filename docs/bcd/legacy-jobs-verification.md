2026-11-01，#73 / #69，Draft PR #74。恢复本轮开发，此前暂停记录仅属历史。

v4租户初始化在旧队列重启恢复之前事务转换全部七种旧状态：queued/running→interrupted、applying→conflict，其余done/error/conflict/interrupted保持。旧任务eligible=false、verified=false，不转换成可调度v4任务、付费块或发布凭据，不自动重新收费或二次发布。未知状态、损坏请求或不安全输出拒绝迁移。

新增tenant-legacy-jobs组件1，旧队列tenant-jobs最低写入版本2、tenant-sync最低写入版本3（防止已连接旧写入器重新存全文）。不可改删收据保存原状态、目标状态、请求/输出/原行/目标行hash；重复执行逐行核对，不因旧标记丢失重新补签。原子回滚同时覆盖DDL、状态、清理和游标。正式全集停写及指针切换仍须另行实施，本增量不能作为在线整库迁移承诺。

删除旧任务request的指令/正文副本，保留ID/类型/不可自动继续标记。只保留128000字节内的小型结构化旧结果作未验证核对，拒绝原始信封/输入字段、超长字符串及累计超过2000字符的引文，不静默截断。未验证输出最多七天，启动、分钟清理和查询时清除，追加处置收据，原hash与已保存事项保持。源库隔离副本的备份期限与物理页/WAL残留仍须按整体迁移/运维规则处理，不能声称法证擦除。

sync_records.sources中的重复输入或附件提取全文清空，规范用户text、原件描述、事项、完成状态、排序、引文保持；每条清理递增同步游标和记录版本，保存前后hash。没有规范输入/原件归属的唯一文字源拒绝清理，避免丢失唯一原文。v4后续同步不再持久化客户端sources预览缓存。原始ai_usage状态保持，v4初始化不再用转换后的队列覆盖旧账本历史。
