## 实现

统一声明和校验已初始化的27类组件：先前9类核心、14类旧任务组件、阅读版本登记表及3类已有独立保护组件。租户12类、账号2类、独立账本13类；按功能初始化，不表示每个既有租户都已完成全集迁移。

新增覆盖旧队列、阅读任务/发布/块、根、复用、窗口、对话请求/凭据、视觉结果/凭据、语义/历史关联结果与凭据、独立根安全及付费证明。原有SQL保持，租户reading版本2显式拥有packet索引。缺失表/索引/保护触发器或不符结构拒绝启动，不能通过启动自动补建掩盖损坏。

既有window-safety/provider-receipts/history-association迁移接入统一引擎，同时保留reading_schema_versions原始SQL校验记录；两套历史在同一事务推进，版本数/摘要不一致失败关闭。未版本化的精确兼容结构可接纳，缺历史标记的受保护结构不能自动补签。

九类核心追加最小写入版本：ledger-core 3，其余8类2；只增加迁移记录与写入门禁，不改业务行。旧二进制重新打开升级库会拒绝未来版本，已打开旧连接的INSERT/UPDATE/DELETE也被版本门禁拒绝。版本化结构不替代停写锁与跨库原子切换。

账号认证模式额外核对：已有V4结构却缺auth_v4、V4同时存在旧active_slot单设备索引、非空旧库丢索引均拒绝，不误退回邀请模式。新建空库保留正常初始化路径。

阶段A夹具再冻结aad1903的sync-jobs，连同此前3份模块共4份，逐字节来源/hash保留在[固定来源](../../scripts/stage-a/legacy/README.md)。新的旧任务升级夹具只在专用临时目录制造独立基线文件，不从已升级数据库删除保护来模拟旧库。双端回退故障测试通过已验证当前schema的合成写入器注入，不注册恒定返回值绕过门禁，没有生产开关。
