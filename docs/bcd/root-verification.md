# 根任务累计与24调用检查点

2026-10-28，北京时间。Refs #73 / #69，现有feat/bcd-attachment-loop / Draft #74。生产v3未启用，B/C/D整体未完成。

## 行为与边界

同一packetId的任务关联首次taskId作为根任务；停止、清除、修改正文后换taskId都不重置累计调用、活跃时间、检查点和时间待核对门禁。明确另一次投递使用另一packetId，其执行时限独立，但账号累计20元、站点每日50元及unknown费用仍共账；不用文件哈希合并用户另一次主动提交。

调用计数取租户任务累计值与独立账本sent/settled/unknown总数的较大值，覆盖发送后、任务计数写入前崩溃；费用取本根在独立账本的结算，不混入其他根或其他账号同名taskId。已清除任务保留计数和最小安全元数据；根进度只保留已校验付费块fingerprint，无原文或结果，不复活已清内容。

第24次调用结束时记录调用数、有效块数、本根消费、unknown风险和活跃时间，不等第25次才检查；无新增有效块则暂停，换taskId不能洗掉。24不是总上限，长材料回归超过24次正常完成。成功块、信封恢复和已有有效块都核对指纹。活跃时间跨任务相加，排队按broker timing排除，供应商timeout受根剩余时限约束。旧执行未排空时拒绝同投递新任务，防止并行绕开根边界。

崩溃遗留running/applying的最后活跃区间无法准确核算时，保留ACTIVE_TIME_RECONCILIATION；有限关闭遗留读取同样如此。停止/清除不能清掉根门禁。已完成计时的正常关闭、无执行区间的崩溃queued维持既有行为；不把未知时间猜成0。

仅显式受控v4初始化新增根元数据表和索引，关联已有任务并核对有效付费块。历史累计达24次而无根检查点时，不能仅据旧每task快照声称整个区间有进度，标CHECKPOINT_RECONCILIATION；重复初始化幂等。旧reading_checkpoints保留，新检查点写reading_root_checkpoints。生产影子迁移器和独立恢复水位尚未实现，不能直接升级真实资料。

双端设置显示本任务调用、该投递累计调用和活跃秒数。v4返回rootTaskId/rootCalls/rootActiveMs/rootActiveSeconds/rootSpent/checkpointCalls/nextCheckpointCalls；小程序视图显式转发，v3没有根字段时兼容隐藏。根门禁显示中文原因并隐藏继续，仍允许有效部分/清除。维护者审计解除入口尚待实现，不用直接改库充当用户操作。

## 实际验证

- 本机74项读取/账号/关闭/格式/恢复回归通过。24次无效付费输出分散到24个taskId并逐次purge，根记录24调用无进度；第25个新任务无新调用。新投递独立根但费用共账。
- 累计1800000ms后清除、改输入、新taskId仍EXECUTION_LIMIT；未知时间和崩溃running重启门禁保留；历史升级两次、有效指纹和消费不变。原有长材料、迟到、信封恢复、来源和分页仍通过。
- Windows源码Electron实际XLSX上传、停止、继续、发布、重载材料面板与累计文字通过。Windows签名HTTP和小程序实际Page的rootCalls/rootActiveSeconds一致。同步/小程序124项、官方WXML/WXSS编译及模板渲染、网页/TypeScript构建通过。
- 相关40项浏览器（bucket、reading-coverage、mini-ui，desktop/mobile）通过；独立release2项及PR/双端门禁8项通过。新模块进入release显式清单。复用无关既有绿灯，最终自身必需CI另核对。
- 独立Linux Node24.20.0普通UID串行任务/关闭/重启28项通过。首次命令因遗漏desktop测试源码使clients加载失败，不能称整个命令成功；补齐desktop与小程序CommonJS声明后clients三项通过。首次进程10.03秒/最大RSS205032KiB（含失败加载），客户端补跑3.45秒/145092KiB；单次观察，非P95。

## 查询测量与质量

[固定合成查询](evidence/root-query.json)由scripts/reading-root-benchmark.mjs生成：1/100/1000个已清除历史任务，各5次暖内存查询；独立账本走合成reserve/sent/settle，故意加入其他账号同taskId消费，逐次核对编号、调用、时间、消费、有效指纹和unknown风险。1000任务跨400参数分批，未超SQLite参数限制。

Linux对应P95约0.42/0.58/8.82ms；1000历史任务返回最近100项的v4路由P95约59.70ms，进程最大RSS91272KiB。列表在一次响应内复用同投递根快照。五样本最近秩P95即最大值，这是暖内存库/模拟费率/共享宿主的查询成本，不是生产磁盘延迟或全账号压测。解析器未改，既有125次读取测量不冒称本增量新证据。

## 剩余与回滚
