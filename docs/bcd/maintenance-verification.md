# 已知累计时限的维护审计扩展

2026-10-29，实现前决策，基线91a7892，Refs #73/#69，Draft #74。

先实现已知累计时间耗尽后的受信维护核对扩展，不把unknown费用/未知活跃时间/安全水位回退门禁清空。需要显式注入维护鉴权、操作编号、维护者元数据标识、证据SHA-256和被审查的独立水位版本；无鉴权默认关闭，无普通用户HTTP入口。E管理网页/受保护CLI接线另验收，不由客户端传管理员身份解除。

独立ledger追加根级时限审计收据，包含原/新时限、累计时间/调用及证据hash，不包含正文。只增加该根的允许执行时间，不增加20元个人额度或50元全站额度，不减少根累计/检查点/费用，也不自动发新请求。幂等操作内容不符拒绝，过期水位/在途执行/未知费用/未知时间/回退门禁拒绝。收据持久后再由用户继续，换taskId/改输入/清除仍沿同根继承累计与已审计时限。

双端沿现有任务错误与动作展示“维护核对已延长时限，累计费用与时间保留；可继续”。不必为了文案另改共享模板或重复生成；恢复后同hash读取、有效付费块、页游标和累计账本都沿现有链，源码Electron与Page/HTTP分别验证。不能把本地回调冒称已上线管理接口，不能冒称未知费用或全域维护解除已完成。

审查补充：仅无在途的paused/interrupted/cancelled/error任务可扩展，queued/running/applying不能借维护扩展自动开跑。任务视图提供`maintenanceOperation`，继续请求绑定`expectedMaintenanceOperation`；未审计时null兼容旧v4，审计后缺失/旧收据的待重放继续动作拒绝STALE_TASK。Windows与小程序保存新动作时绑定当前收据，旧稳定动作编号不偷偷换成新收据。旧成功动作仍按原凭据幂等返回；动作与收据投影同一租户事务提交。测试预置崩溃遗留待继续动作，经两端真实同步重放后均明确拒绝并清空，确认零模型调用，刷新后由用户新动作继续。

根允许时间可以审计延长至初始1800秒以上，但单次broker入场预算仍最多1800秒，解析30秒/内存/输出及模型240秒限制不变。不是提升隔离限制、退款或清零；长根通过连续有限步骤完成。
