# PNG隔离瓦片、模型输入与双端接续

基线46e9fe0，Refs #73/#69，继续Draft #74。此为B中的静态PNG明确子集及其C/D接线，不是图像全格式、扫描PDF或B/C/D最终联合验收。

## 实现与边界

隔离内校验原hash/大小、PNG各chunk CRC/结构/IDAT终态及zlib实际输出上界。仅8位、非交错静态灰度/RGB/索引/alpha；按过滤器0–4还原逐行像素、透明度按白底显式合成。未知关键块、动画、16位/交错、方向及未实现的色彩/HDR/背景解释明确拒绝，不擅自忽略后声称读完。tRNS按PNG规范屏蔽未使用的高位。依据[W3C PNG第三版](https://www.w3.org/TR/png-3/)，原创解码适配使用Node内置zlib，不安装OCR/宿主软件包。

单图≤32,000,000像素、边≤16384保持；1024×1024区域按行顺序穷尽，保存原坐标、尺寸、原hash及归一瓦片hash。每窗仅一块，确认付费块后推进元数据游标并释放图像；停止/重启重读当前原件与未确认窗。数值64是上述像素/边界下的保守游标校验范围，不是材料/根任务总硬顶。归档/Office里的图像仍明确未读。当前区域不重叠，跨边缘文字/关系及跨区域重复事项仍需语义合并与质量改进，不宣称无漏识别。

broker协议5仅接受tile数字游标，拒绝路径与额外字段；沿原RootDirectory/DynamicUser/无网络、512MiB/30秒等隔离，不降级普通进程。主服务核对游标连续性、原尺寸/区域几何、图像hash及信封。请求只用data:image/png，最多2张/16MiB，不用外链或Files API；模型image tokens按当前官方每图≤1024与文本UTF-8保守上界预留，冻结价格结算。依据[Flash图像文档](https://api-docs.deepseek.com/guides/vision/)与[人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，2026-10-29重新查证；原模型240秒/unknown/停止generation/根累计/24检查点不变，无盲目重发。

只保留结构结果、每引用≤500/每附件累计≤2000及来源坐标；像素、base64、完整转写不存任务/块/窗口/账本。图像引文由模型识别，不套用“本地全文包含”假证明，统一加对照原图提示。日期从模型识别的有界引文推定，仍可能识别错误。达到引用隐私上限后的locator-only有效块，只有精确证书/结果hash/当前图像/模型与录入日上下文一致时复用，保留已校验日期，不为重建已丢弃引文重新计费；不降低文本引用校验。有效usage在后续引用校验失败时仍独立结算，避免残留sent。

## 必要开发验证

固定2071×1031图案经6个瓦片重组，核对独立原RGBA的全部像素/hash、行序、来源唯一性、覆盖/坐标与最后像素。另有前行非零的5种滤波固定RGB golden、灰度/索引透明、隐藏RGB白底、CRC损坏、尺寸、解压膨胀、动画/色彩、游标注入、供应商图像信封与预算。不是只验非空或模拟OCR。

任务专项实际磁盘租户：首块付费→停止→新engine→重核验→3块发布→修改输入精确复用；任务/块/窗口均无图像数据。5区域、2500字符引文样本验证累计2000隐私上限后最后块仅locator，修订后复用5块且原18:00仍保留。无图像能力/坏PNG零模型调用，引用校验异常仍结算可信usage。

两端[Linux结构化报告](evidence/image-clients-linux.json)经受保护broker普通UID，在temporary过期/删除墓碑两链核对3个区域几何、尾部/结果一致、跨端停止继续、迟到响应丢弃及修订复用3块。每链5次模拟调用100微元，含已发送后停止的1次和修订新文字1次；根累计不回退。链单次约3.67/3.87秒，不是模型时延/SLO。真实32MP固定白底样本末块峰值438100KiB、单次约3791ms，1MP基线81196KiB/461ms；在512MiB隔离内，不据单次称P95/容量。代表性压力不反复重跑未变矩阵。

本地受影响内核92项通过（随后补PNG透明度/色彩及前行滤波两项、最终隐私复用等定向）；同步125、release2、TS/网页构建、15生成文件、官方WXML/WXSS编译与模板渲染通过。新增共享函数首次未列入mini生成导出，Page测试先失败后补生成器并mini:build，随后两链通过。删除链最初让无本地副本的另一设备启动，正确返回补传所需；改为持副本设备启动后通过，没有放宽原件门禁。新增引用校验先暴露本地文本contains校验不适于图像，已改为图像来源/短引用及统一识别提示，并补异常可信usage结算回归。完整必需CI在远端跑，不在本机重复历史窗口测试。
