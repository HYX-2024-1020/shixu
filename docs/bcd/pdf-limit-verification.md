## 定向定位与决策

沿用原531269字节/241页固定合成材料和既有约24.8秒外层拒绝基线，不重新制造材料迎合结果。先试逐8页document.cleanup，仍拒绝，撤回无效改动。一次cgroup采样回答“是否OOM”：峰值约88MB、oom/oom_kill均0、CPU受50%配额节流，不能再把拒绝推断为内存不足。

将阈值仅在内部测试入口下调到120字符，以子进程复现PDF.js同进程文字流cancel后尚有enqueue消息，Node报ERR_INVALID_STATE/Controller is already closed并退出。生产仍固定8Mi UTF-16文字上限，测试入口只允许正整数且不得高于该阈值，未暴露在broker或HTTP描述符。

修复为触限时不再保留当前页文字、排空该页文字流至明确终态，随后保留此前完整页并标明当前页至末页未读；不取消仍在投递消息的流、不提交当前页前缀、不越过阈值继续下一页。每次仍受原512MiB/CPU50%/30秒/64MiB输出与根剩余时间限制；若排空当前超大页仍遭外层终止，整文件继续失败，不能捏造前缀。读取版本提升pdf-text/2，旧证书不得冒用新行为。
