# PDF有界页窗口与任务游标

2026-10-29，基线bb8e427，Refs #73/#69，同一Draft #74。实现中，不表示B/C/D已完成。

## 实现前决策

仅顶层PDF先采用每次最多8页文字窗口，不是整份页数上限，也不是渲染页数配置；每窗口仍受8Mi文字、512MiB/CPU50%/30秒/64MiB输出及根剩余时间限制。每页只有完整终态才能进入来源。若单页无法推进，明确保留资源遗漏，不死循环或提高限额。ZIP内PDF的窗口化另待接入，不能以顶层支持冒称归档全覆盖。

broker仅新增经过严格验证的页码/Unicode累计offset参数，不接受任意路径/命令/worker/资源限制；原字节始终重新核对长度/hash。PDF来源编号按页码和页内片段稳定生成，完整一次读取与多窗口读取可逐项对比。返回窗口起点/下一页/累计offset/总页数，当前窗口文字仍仅在执行内存。

任务检查点只存原件hash、下一页、累计Unicode offset和覆盖。当前窗口所有可用处理块均已有有效账本/结果后，事务推进游标、释放该窗口正文，让出调度，再读下一窗口；停止/重启/补传先按同hash核验，从未提交窗口重读并复用有效付费块，不保存全文。非PDF材料完成后不随每个PDF窗口反复读取。根调用/时间/24调用检查点及unknown门禁贯穿所有窗口。

历史覆盖与当前窗口合并，移除已被后续读取替代的等待范围，保留视觉未读/无文字/真实失败范围。部分收下列出已整理、已读取但未整理、后续尚未读取三类实际范围。两端显示已检查页数/总页数，仍不将PDF视觉内容标完整读取。版本变化不冒用旧来源或旧证书；旧broker不支持窗口参数时失败关闭，不能静默重复首窗。
