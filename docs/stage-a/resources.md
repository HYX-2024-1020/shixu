# 阶段 A3：资源配置与验收矩阵

依据 [阶段 A](README.md)。单位MiB=1,048,576字节；方案中的10MB/20MB/500MB在接口统一展示与配置为10MiB/20MiB/500MiB，客户端同步显示实际字节限制，不能前端按十进制允许而后端按二进制拒绝。以下是起步配置而非实测容量保证；不能用任意提高上限绕过安全失败。

## 上传、解析与隔离配置

| 参数 | 起步值 | 理由 / 执行位置 / 验证 |
| --- | --- | --- |
| 单原件/整次/件数 | 10MiB / 20MiB / 20 | 沿用方案；入口流式计数+最终manifest/hash；测试恰好/超1字节、谎报长度和并发预留 |
| 每账号长期逻辑原件 | 500MiB | 回收/待清理计入；SQLite事务配额；测试满额续期与整次temporary |
| 一次归档解压总量 | 64MiB | 20MiB输入最多约3倍临时工作放大；流式累计，不能仅信元数据；超限隔离该归档并列未处理范围 |
| 归档条目/压缩比 | 1,000 / 100:1 | 防小文件/高压缩炸弹；单条与累计均验（累计还受64MiB限）；目录也计条目 |
| 归档嵌套/路径 | 0层嵌套；UTF-8路径≤512字节、深度≤16 | 嵌套包只作未读项，不递归；拒绝绝对路径、盘符、../、符号/硬链接、设备/FIFO/重解析点；跨平台恶意样本测试 |
| 图像原始解码 | 单图≤32百万像素，边≤16,384像素 | 解码前验尺寸，再验实际像素；约128MiB RGBA上界；异常图隔离，不静默缩小后称完整读取 |
| PDF每批渲染 | 2页，每页≤8百万像素 | 批峰值约64MiB RGBA；分页游标持久；整份页数不设硬顶；超尺寸页分瓦片并记录范围 |
| 图像模型每批 | ≤2张、编码后请求≤16MiB | 控制base64与内存放大，低于供应商当前限制；大图分瓦片核对来源；模型能力/上限变化须版本化 |
| 文本窗口 | 120,000 Unicode码点 | 长文持续分块；token最坏上界另按模型校验，必要时缩小每块；测试跨中文/emoji/表格边界无遗漏 |
| 解析单步骤墙钟 | 30秒 | 超时杀整个cgroup/process组，记录范围失败；其他安全附件继续；不得仅Promise超时留下后台进程 |
| 模型/合并单步骤墙钟 | 240秒 | 复用现有请求量级，超时已发调用转unknown；不盲目重发 |
| 总执行时间 | 每task累计1,800秒活跃时间 | 排队/人工暂停不计，识别/合并/重试均计，重启/继续不清零；耗尽暂停execution_limit，管理员审计调高后用户才能继续；不变成页数/字符总硬顶 |
| 安全自动重试 | 最多2次 | 仅确定未发/未计费的短暂错误或可安全重复解析；unknown不自动重试；累计计数不清零 |
| 解析并行/CPU | 全站1；单worker CPUQuota=50% | 给同步/下载留余量；cgroup限额，实际2vCPU机器只是容量验证起点，不声称当前ECS已核对 |
| 解析内存/进程 | MemoryMax=512MiB、MemorySwapMax=0、TasksMax=16 | 32MP解码+2页渲染不可同时做，按阶段释放；fork/线程也计Tasks；超限终止，主服务存活 |
| 单任务临时空间 | 256MiB，受限文件系统；最多1个解析工作区 | 64MiB解压+64MiB转图+输入20MiB及工具开销，留约100MiB余量；硬配额而非事后统计 |
| 全站临时空间 | 512MiB（含上传staging），20个等待任务只存manifest/原件引用 | retained待处理从长期原件读取；temporary满额则背压/拒新上传，不把20份展开内容排队；磁盘80%同步触发暂停 |
| 模型并行/公平 | 全站3、每账号1未完成、等待最多20 | 按账号轮转每次一批；解析和模型队列分开，长任务让出；有槽位不代表必须同时发3次 |
| 调用检查点 | 每24次、rootTask累计 | 费用/资源/覆盖进度校验，正常继续；持续失败/无进度暂停，不能清零无限重跑 |
| 模型输出/单次事项 | JSON≤1MiB、最多200事项 | 超限块失败可缩小范围重做，不能截断后标完整；sourceId/字段类型/深度≤32逐项校验 |
| 查询/普通JSON | 列表每页≤100、普通请求≤1MiB | 上传独立流接口；预览按范围分页；基本功能不随AI排队，测P95和错误率 |

Linux实现采用受限worker根文件系统（只读解析器和依赖）、单次输入只读挂载和唯一受限scratch；独立低权限UID、PrivateNetwork/IPAddressDeny、NoNewPrivileges、CapabilityBoundingSet清空、PrivateDevices、ProtectSystem/ProtectHome、拒绝AF_INET/AF_INET6、仅允许必要syscall，cgroup限制CPU/内存/pids。输入经broker交付，worker无账号注册表、账本、模型key、宿主临时目录和其他任务路径；env白名单、无HTTP代理配置。不能仅设置systemd几个选项后声称隔离完成。依据 [systemd.exec](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html)，B必须尝试联网、越路径/链接、fork、内存、磁盘与超时逃逸；不具备内核隔离能力时读取器拒绝启动，不能降级为普通子进程。Windows仅作受控客户端，正式解析隔离在Linux服务器验证。

解压格式/魔数不一致、加密、宏、音视频/脚本不执行，外链不访问；一般安全文本文件可作为文本处理。PDF/Office中的嵌入对象不执行也不访问远端关系。DOC/XLS和嵌套包依方案标unsupported；不能借桌面已存在的旧Office解析器扩大本轮格式范围。

## B–F必须保留的验证矩阵

- B：每种格式真实合成样本、扫描长PDF、跨工作表/压缩路径、完全/部分失败、所有上限边界及恶意逃逸；图像输入不能由文本mock冒充。没有付费授权核算前只做本地解析/模拟模型。
- C：跨连接并发预留、usage结算幂等、跨日unknown、停止/继续迟到响应、重启与发布中断、账号公平和24次检查点；每任务超过2元累计可正常完成，验证2元只是同时在途上限。
- D：Windows源码隔离profile及微信develop工具同一合成账号，三台Windows+同微信重装、满槽替换/撤销、账号密码迁移、临时模式清理、满额续存、离线写锁和旧客户端降级。验证本地文件保存失败与双方均不留时确认。更新能力表，分别记录真实执行的两端证据。
- E：实际服务备份/恢复/回退，最新账本配老资料、删除/撤销重放、快照写入失败/磁盘满/过期备份、管理CSRF/越权、普通用户无正文管理路由。非网页隐藏替代接口权限。
- F：10合成账号混合上传/长任务/查询/手动编辑；同步/下载P95目标<1秒（排除网络传输）且无AI队列阻塞，超目标先降并发/背压再复测。真实DS总验证批次≤10元；固定包部署需要单独授权和运行核验。

A已验证配置逻辑关系，不声称上述B–F实际检查通过。备案前禁止真实账号开放、安装版/手机公网验收；备案/DNS/HTTPS/微信域名后另补正式开放门禁。
