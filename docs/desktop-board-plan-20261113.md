## 目标与首版边界

在使用其他软件时，持续看见自己选择的未完成事项，并管理短期安排、长期计划及手边资料。不是只显示今日任务，也不把主程序全部事项强行铺满桌面。

Windows 首版为主程序独立「看板」页、多份命名规划和单个悬浮看板，提供小条/窄栏/面板/DDL四个同级入口。切换入口复用当前规划，不产生四份互不相干的数据或四个独立悬浮窗口。

不加声音、主动提醒、催促弹窗、定时回顾或自动轮播；不加入专注计时等候选功能。普通新增、编辑、完成不调用模型。小程序本轮不实施悬浮窗口；接入时评估共享数据影响并更新双端能力表，不冒称手机交付。

## 入口与内容结构

| 同级入口 | 内容与用途 | 不得回退的规则 |
| --- | --- | --- |
| 小条 | 约250px宽，收起约32–40px高；默认一件未完成/固定事项及展开按钮 | 展开保持小条页面和宽度，略增高度显示2–3件事项、数量和最近截止；不能跳到窄栏 |
| 窄栏 | 约340–360px宽；顶部「短期计划／长期计划」两个页签，一次显示其中一页 | 不含DDL页签、随手记或旧版「展示模块／只看短期」开关 |
| 面板 | 图片和文件的资料库，提供画廊／表格 | 不再只是将短期、长期、随手记从下方移到右边 |
| DDL | 独立截止雷达，默认读取全部主程序DDL及本规划有日期的手写事项 | 与小条/窄栏/面板同级，不受短期计划选入集合限制 |

### 短期计划

- 展示独立短期事项、选入的主程序事项、长期计划关联的子事项，明确区分来源。
- 列表下方「新增一项」创建短期事项；保留从主程序选择事项加入的入口。
- 常用标题、日期、完成和删除等操作在看板内处理；原文、原件和复杂详情打开主程序对应详情。
- 完成后原位淡化划线并保留完成日期，可取消完成，不立即消失或自动清理。

### 长期计划与子事项联动

- 长期页展示多项父计划；整个列表下方「新增一项」创建新的长期父计划。
- 每个父计划内部单独手动新增子事项，不用AI自动拆步骤；可逐日继续补充、编辑、排序及指定下一步。
- 新增子事项自动关联到短期计划，使用同一个稳定标识。两个视图的标题及完成状态保持一致，不能复制成两件独立事项或重复计算完成数。
- 子事项完成后原位淡化划线、记录日期，跨日保留；取消完成更新两处展示。
- 单条/批量归档已完成步骤，收在父计划的「已归档」中，可展开和恢复展示；恢复不抹掉完成状态与日期。归档步骤从日常短期列表收起，保留记录；隐藏页签、切换入口均不删除步骤。
- 紧凑时显示完成数/总数及下一步。全部现有步骤完成只表示「当前步骤已全部完成」，不自动完成父计划，也不催促结束；整个长期计划由用户主动完成。

「随手记」已由用户取消，不再保留独立随手记区、草稿转事项按钮或第二版模块显示开关。普通新增改为两个页签各自下方「新增一项」。未提交输入仍需按既有退出草稿保存契约保护，不能把移除随手记当成允许丢输入。

### 面板资料库

- 留存和展示笔记图片及需用文件；画廊看缩略图，表格看名称、类型、关联计划、添加时间等必要信息。
- 按全部／笔记图片／文件筛选；提供添加、查看详情和打开文件等操作。图片能预览，非图片提供类型与详情，不能冒称所有格式都能内嵌阅读。
- 资料与当前规划、长期计划的关联清楚；新增资料不默认作为桶材料投递或调用模型。
- 前端小样选择文件只在本页面临时预览，不代表已经上传或持久保存。正式接入必须核实本地/云端原件管理、账号隔离、文件验证、大小/额度、保存失败、删除恢复、离线与备份/同步边界。
- 优先复用已有原件与存储能力，不另开绕过账号、费用或原件生命周期的文件后门；也不能未经调查就承诺既有接口已覆盖资料库。资料归属、去重/引用与删除影响须在接入设计中明确并验证，不扩大成通用云盘或其他账号资料管理。

### 独立DDL

默认主程序全部DDL，加当前规划内有日期的手写事项；明确标注来源。短期是否选入某来源事项，不改变DDL全量读取。

支持全部、今天、未来七天、自定义范围；显示绝对截止时刻、倒计时与逾期。无日期不虚构DDL；已有明确/推定时刻、录入日推定、日期区间、人工覆盖与来源依据完整保留，不能重新实现一套冲突的解析规则。

## 规划、来源与一致性

主程序增加独立看板页管理多份命名规划；内容、来源关联、步骤、完成日期、归档、资料关联、布局和上次入口自动保存。启用可「继续上次／选择已有／新建空白」，新建不覆盖旧规划。新规划短期/长期为空，DDL仍默认读取全部主程序来源；示例数据不灌入真实规划。

| 内容 | 归属与影响 |
| --- | --- |
| 选入事项 | 指向原来的主程序事项，编辑/完成同步；移出规划不删除来源；来源删除/恢复按既有规则处理 |
| 手写事项及父计划 | 属于当前规划，不自动进入桶、普通事项或主程序普通DDL；有日期时进入看板DDL，未来可主动转入主程序 |
| 子事项 | 属于长期父计划，在短期页关联展示；稳定身份和操作语义跨视图一致 |
| 资料库资料 | 作为规划资料管理，不能把本地临时预览冒称持久存储；实际原件与同步契约待接入核实 |

移出来源、归档、删除、隐藏和切换入口不能混为一谈。删除要说明作用范围、复用恢复规则；同一子事项或原件的多处引用不能各自写出冲突状态。离线队列、多窗口更新、账号切换、来源删除/恢复及主动转入去重须按现有契约设计，不以复制整份旧源码完成整合。

## 原生窗口与生命周期

保留单个看板的拖动、拉伸、折叠、置顶/取消、隐藏/恢复、快捷键和布局锁定；入口切换及重启不丢内容、位置和配置。默认可使用紧凑窄栏，小条内容可选择固定事项/最近截止/完成数量，不自动轮播。不因鼠标移开收起，不主动弹出抢焦点。

主程序收至托盘后看板继续；明确退出拾序一起退出，退出前刷新未保存输入。关闭/隐藏看板不删除规划。支持启动时恢复看板选项。不能把旧版模块自由重复混排的概念重新套回四入口；原来的布局诉求以当前入口内部的排序、折叠、尺寸、密度等合理配置承接，若需实质改变再明确说明。

Apple Music全屏后仍可见是待验证的Windows场景，不承诺覆盖所有独占全屏或系统界面。核实平台能力并分别记录普通最大化与全屏实测。禁止computer-use/本机桌面UI自动操作继续有效；隔离自动测试与CI可用，必要用户实测给具体步骤。

## 延续主程序风格

小样确定交互结构，主程序截图和实际样式确定外观，不能照搬小样较圆润、柔和的皮肤。详细[风格与前端接续](project-continuity/desktop-board-handoff-20261113.md)及[视觉约束](../design/README.md)。

- 纸黄#fff9e6、暖白#fffef8、墨黑#111/#171713、亮黄#ffd43b，保留粉#f783ac/紫#7048e8点缀。
- 小圆角、明确黑描边、无模糊偏移硬阴影；主程序贴纸式卡片结构适度缩放到工具窗口，不变成蓝紫后台、毛玻璃、大胶囊或柔和阴影卡片。
- Segoe UI/Microsoft YaHei；标题约16–18px、正文13–14px、说明11–12px；4/8/12/16间距。小条优先省空间，窄栏紧凑，面板重视资料可读性。
- 不照搬主程序首页巨字、角色和大留白；不新增角色素材。样式作用域限看板，原主程序布局和#106/#112等修复保持。

## 验收与交付边界

1. 新建/切换/重命名规划不覆盖已有内容；短长期为空而DDL有全部来源，重启可继续。
2. 窄栏两个页签各自新增正确类型；长期父计划中新增子事项自动进入短期，两处编辑/完成同步，没有重复身份。
3. 完成日期跨日保留，单条/批量归档和恢复有效；父计划不自动完成，取消完成不留下虚假完成状态。
4. 主程序事项选择加入、编辑完成、移出及来源删除/恢复范围正确；手写内容不污染桶或普通事项，普通操作无模型请求。
5. 小条保持约250px宽原地展开/收起，增加少量信息但不跳窄栏；固定内容不自动轮播。
6. 面板资料库画廊/表格/筛选/图片预览/其他文件详情有效；真正保存、重启、账号隔离、失败重试、原件生命周期和引用删除有独立证据，不能只验前端FileReader。
7. DDL与其他三入口同级，全量来源、范围筛选、倒计时、逾期、明确/推定时刻、人工覆盖和区间回归通过。
8. 四入口切换、拉伸、锁定、隐藏恢复、托盘/退出/重启及多窗口写入不丢内容；320px及桌面宽度可用，键盘/减少动效/文字对比有效。
9. 保留账号、同步、离线、墓碑不复活、备份、旧卡片排序/完成/重启、草稿与IPC安全门禁。Windows置顶和Apple Music全屏、实际安装入口及物理版本单独验收。

当前小样合成自动验证不等于外部前端或正式产品验收。下一轮先核对用户提供的前端原件、依赖与许可证、组件/样式作用域、mock/真实适配边界及能力缺口，再受控接入并完成后端。真实入口是`src/main.tsx`默认加载的`src/bucket/BucketApp.tsx`，不能误改旧`src/App.tsx`；悬浮窗口需精确扩展`desktop/main.cjs`现有仅主窗口IPC白名单，不整体放宽。

按贡献指南执行适用核心、浏览器、同步、服务与Windows自动化回归；经独立功能PR/必需CI/审查后按既有授权合入。源码、构建、现有阿里云部署、原生用户安装、全屏兼容与用户验收分层记录。当前0.3.26/5d7b42c运行包是历史安装基线，不将文档提交当作已升级；接入时重新核对实际部署安装。不默认付费模型、不清个人资料、不改网站/控制台或顺带启动其他整改。
