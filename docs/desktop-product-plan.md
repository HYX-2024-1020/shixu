# 桌面产品计划

## 当前发行

Windows **0.3.8** 已发布并包含皮肤市场。能力与限制以 [Windows 指南](guides/windows.md)、[0.3.8 说明](releases/windows-0.3.8.md)为准。

已确认的方向：独立软件、两工作区、混合材料一次投递、清楚的本次结果与原文依据、可管理的事项卡片；保持纸黄、描边与硬阴影视觉，继续打磨空间交互和可换角色。

## 后续验收

- 基于最新 main 打磨皮肤预览、互动和编辑，不回到早期静态参考页。
- 补 QQ/微信/资源管理器的文字、文件与临时图片实际拖入验收。
- 接入 v2 云同步：先以隔离 profile 验证完整字段、离线、冲突、删除恢复，再备份迁移个人资料。
- 完成小程序开发者工具/真机验收，再推进附件、AI 队列与配对。
- 继续记录模型读取覆盖与失败原因，不把流程通过等同于语义准确率。

按 [贡献流程](../CONTRIBUTING.md)拆分 Issue/分支/PR。早期逐项完成表见 [历史计划](archive/desktop-product-plan-2026-10.md)，其中旧版本与旧机器状态不作为当前依据。
