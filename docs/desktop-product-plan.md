# 桌面产品计划

更新：2026-11-02。当前状态以[接续入口](current-baseline.md)为准，成果位置和后续推进见[复用约束](project-continuity/README.md)。功能开发保持暂停，本次整理不启动后续条目。

## 已确认方向与交付边界

独立软件、桶/世界/DDL、混合材料投递、清楚的整理结果与原文依据、可管理事项；保留纸黄、描边、硬阴影和已确认的赛璐璐卡片及角色。拾序服务大学学习、通知与任务管理，轻量、顺手，小范围非商业分享。

公开Windows Release仍为[0.3.8](releases/windows-0.3.8.md)；最新本机交付记录为[0.3.23](releases/windows-0.3.23.md)。主线已包含双端DDL、账号/同步接入和后续卡片/角色调整；源码合入、安装、服务器部署、微信工程送达和手机验收分别记录。不得沿用旧“v2尚未开始接入”描述安排重复开发。

## 恢复后的候选工作与验收

- 优先定位手机世界的卡片密度、折叠与操作问题，复用已合入的卡片/排序/详情成果，保留Windows相对舒适的现有体验。
- 通过代表性通知核对AI分类、分组与命名，复用shared规则及未合并语义成果，不以格式数量替代质量。
- 应急网页与小程序分别定位文字、适配、角色和音画问题，不因Windows测试通过否定手机反馈。
- 云端资料、同步、删除与恢复作为可靠性保障；保留B/C/D已有成果和安全门禁，按依赖与运行模式分批验收。
- 常见材料缺口按使用场景排期；罕见格式扩展冻结，已完成能力不丢弃。QQ/微信/资源管理器真实拖入、原生手机与正式网络仍须独立证据。

具体任务在用户恢复后建立Issue、专用分支和PR，不在本计划或大Draft分支无止境追加。原方案与总清单仍保留，不自动更改契约。[DDL记录](ddl.md)、[双端能力表](client-parity.md)与[历史计划](archive/desktop-product-plan-2026-10.md)保留追溯。
