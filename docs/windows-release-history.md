# Windows 历史版本

当前下载：[v0.3.7](https://github.com/HYX-2024-1020/shixu/releases/tag/v0.3.7)。以下版本保留为追溯记录，不作为新用户入口。

0.3.6 打磨交互动画：卡片与弹窗自然展开、菜单轻微回弹、完成勾选后退出、删除后周围卡片平滑补位，星标与按钮有轻量反馈，拖入/拖出和工作区切换有衔接。动画可被连续操作打断，不阻挡继续输入；保持原有纸黄、描边和彩色硬阴影。按用户要求，不提供减少动态效果选项。

0.3.5 支持点击整理内容和来源文字中的网页链接，交给系统浏览器打开。首页不再堆叠历史回执；世界页“整理记录”保留按需查看、失败重试和来源修正。修复取消拖入后蒙层残留；删除位于卡片上方，无撤销提示，最近删除仍可恢复。完成有勾选动画，详情操作统一右下角，菜单点击外部自动关闭。

0.3.4 菜单“编辑内容与分组”直接打开表单；“和 AI 说一声”支持当前卡片多轮对话，例如“这是通知，移到通知分区”“归入人工智能课程”“标题改短一点”。使用当前配置的模型，修改即时应用、对话和依据保留，调用计入用量。旧的文字补充不会自动发送。

0.3.3 支持每事项自由补充信息，概览聚焦简短标题与关键要求，不默认催促“待确认”。点击卡片底部“同行材料”直接预览图片、翻阅 PDF，Office/压缩包展示已提取文字；图片可放大，保存原件位于更多菜单。AI 建议采纳后就地显示“已采纳”，防止连续点击重复创建行动。
