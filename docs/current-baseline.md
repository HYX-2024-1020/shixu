## 本地目录与接续规则

- `shixu-baseline/`：本次独立整合 checkout，分支 `chore/consolidate-current-baseline`。从更新后的 origin/main 起步，吸收治理分支及明确列出的本地皮肤/同步/小程序/部署文件。
- `shixu/`：原工作目录，仍保留其他对话产生的未提交文件。本次不 reset、clean、stash，也不覆盖它们。不要将它仍显示脏工作区误认为远端未保存；先与整合提交比对。
- `shixu-governance/`：治理旧 checkout；保留至本次 PR 合并，随后只作历史接续参考。
- `shixu-card-motion/`：0.3.7 隔离目录及构建产物；不再作为后续主开发入口，保留供安装验收追溯。
- 根目录旧 `shixu-release.tar.gz`、各 checkout 的 dist/release 不作为当前版本依据；当前安装包以 GitHub 最新正式发布及其校验值为准，不上传这些本地产物。

后续任务先读根目录 AGENTS.md 和 CONTRIBUTING.md，再从最新 origin/main 创建任务分支/独立 worktree。不要直接在原 shixu/main 的遗留混合工作区继续叠加开发。
