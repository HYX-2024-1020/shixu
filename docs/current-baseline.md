## 后续顺序

Issue #17 的 0.2.0 开发分支正在迁移桌面事项工作流、皮肤、同源 AI 队列及[原件同步](miniprogram-attachments.md)；详细实现/差距见 [双端能力表](client-parity.md)。该分支的源码检查不代表合入 main、云端部署或微信发布。0.1.0 工程已由用户确认模拟器打开与草稿重新编译保留；0.2.0 工程和自动化接口已连通，交互验收按用户游戏期间不操作电脑的要求暂未执行。

1. 小程序开发者工具编译与 iPhone 真机验证，以合成资料验收文字同步闭环。
2. 配置可核验的 HTTPS 服务与客户端连接，固定快照发布并验证恢复。
3. Windows 以隔离 profile 验证完整字段、离线、冲突与删除恢复，再备份迁移资料。
4. 加入服务端附件、AI 队列、微信导入与配对。
5. 持续打磨已进入桌面发行的皮肤市场；补真实来源拖拽与第三方授权记录。

## 接续规则

从最新 origin/main 创建任务分支；有遗留未提交内容时使用独立 worktree。以 Git、PR 和 Release 为交付依据，不以本机某个旧 release/dist 目录或历史聊天日志判断当前版本。已发布标签和安装包保留，不重写；源码提交不代表服务器或安装包自动更新。
