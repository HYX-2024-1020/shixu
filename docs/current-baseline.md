## 接续规则

从最新 origin/main 创建任务分支；有遗留未提交内容时使用独立 worktree。以 Git、PR 和 Release 为交付依据，不以本机某个旧 release/dist 目录或历史聊天日志判断当前版本。已发布标签和安装包保留，不重写；源码提交不代表服务器或安装包自动更新。
