# 拾序 Shixu · 前端交接说明（给后端 agent）

## 入口文件
`shixu.html` — 单文件前端，HTML + CSS + JS 全部内联，无构建步骤、无框架、无外部依赖（仅 Google Fonts 两套字体）。

## 素材目录
```
assets/
  mascot.png       # 吉祥物「鲸鱼娘」张嘴帧（透明 PNG，512×509）
  mascot_user.png  # 用户提供的原始抠图
  mascot_original.png / candidates/*.webp  # 原始素材与候选，后端不需要
  laugh.mp3        # 吉祥物笑声（从用户录屏提取，13.5s）
```

## 核心产品概念（后端要理解的世界观）
- **拾序** = 「一个什么都能放的桶」。用户把通知/截图/文档/灵感随手丢进来，**不预先分类**。
- AI 自动做四件事：① 提炼待办/要求/截止时间；② 整理资料；③ 把同一课程/项目的相关内容**归组**；④ 保留原文和附件供核对。
- 界面两大工作区：**「桶」**（轻松输入）和**「世界」**（整理结果）。

## 数据模型（前端已固化的字段，后端需按此约定返回）
前端目前是纯静态演示数据，`detect()` 函数对输入做了类型识别。后端实现时要保证这几个概念对应：

| 概念 | 前端表现 | 说明 |
|------|---------|------|
| 投递项 item | `.chip` / 收集箱 `.file` | 有类型 `img`/`doc`/`idea`（图/文/灵感），检测规则见下 |
| 待办 todo | `.todo`（可勾选） | 字段：`text`（标题）、`src`（来源文件）、`deadline`（截止，`hot` 表紧急） |
| 分组 group | `.group` 卡片 | 字段：`name`（如"数据结构"）、`tag`（CS201 等）、`remaining`（剩余待办数）、`sub`（说明） |
| 习惯 habit | `.habit` | 字段：`name`、`small`（说明）、7 天打卡数组、`streak`（连续天数） |
| 原文 | `details.raw` | 每条待办可展开看原文，`<em>` 高亮 AI 提炼的关键信息 |

### 前端已写死的类型识别规则（`detect()`，供后端对齐）
```js
/\.(png|jpe?g|gif|webp|bmp)$/i  → 类型 img（图）
/\.(pdf|docx?|pptx?|xlsx?|md|txt|eml|zip)$/i → doc（文）
/^(通知|公告|转发)/             → doc（通）
其余                              → idea（灵感）
```

## 交互/动画（后端无需改，但要知道触发点）
- **投递**：输入框提交 / 页面任意位置 Ctrl+V 粘贴 / 拖文件进来 → 触发 `addItem()`。
- `addItem()` 是前端唯一"接收新数据"的入口函数。后端接入时，把真实接口返回的 item 喂进 `addItem(text, x, y)` 或直接改 `commitItem()` 即可。
- **唐笑**：`laugh()` 函数，点吉祥物或吞下投递后触发，播放 `assets/laugh.mp3` + 头上下弹跳 + 「哈」字弹幕。
- **页面切换**：`goWorld()` / `goBucket()`，底部大胶囊「桶 ⇄ 世界」。
- **待办完成**：`.todo input` 的 change 事件 → `refreshCounts()` 更新剩余数。

## 后端对接建议（改哪几处）
1. 把 `shixu.html` 里的静态分组/待办/习惯 HTML，替换成从接口 fetch 后动态渲染（或用模板）。
2. `commitItem()` 里目前是纯前端本地计数 + 塞进「收集箱」，后端应该改成：投递 → POST 给 AI 整理接口 → 返回归组结果 → 刷新「世界」页。
3. 字体用 Google Fonts CDN，若离线环境需自托管或改系统字体栈。

## 视觉规范（如果要新增 UI，保持一致性）
- 风格：新粗野主义 Neo-Brutalism。纸黄底 `#FFF9E6`、墨黑 `#111` 3px 实线描边、5px 硬阴影、圆角 4px。
- 主色亮黄 `#FFD43B`，点缀电紫 `#7048E8`、桃粉 `#F783AC`。
- 标题 Black 900 粗字，标签用 Space Grotesk 全大写宽字距。
- 所有可交互元素都要有 hover/active 的位移 + 阴影变化。
