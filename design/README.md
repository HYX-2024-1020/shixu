# 界面与视觉约束

当前界面使用纸黄底、墨黑描边、硬阴影与亮黄主色，保留粉/紫点缀、角色与底部「桶 / 世界」导航。界面改动以当前 src/bucket/ 实现和用户已确认的布局为基准。

- 结果默认事项卡片，分组是可选视图，不增加「未分组」占位。
- 卡片详情直接呈现要求、依据和同行材料，原件留在对应投递中。
- 保留原位开合、长按拖动、完成/删除后的平滑补位与本次投喂反馈。
- 皮肤市场改变角色及互动，不另建一套过时的桌面布局。
- 短窗口、触屏、安全区和窄屏做必要适配，不借机重做整体视觉。

运行图像/音频/字体位于 public/，皮肤插画在 SkinArt.tsx。早期静态参考页及重复素材副本已移除，历史仍可从 Git 查看；字体许可与既有角色授权待办见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

当前产品截图见 [README](../README.md)和 [Windows 指南](../docs/guides/windows.md)，均来自隔离测试资料。
