## 导入工程

1. 安装官方 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，使用该小程序管理员微信登录。
2. 选择“导入项目”，目录选择当前 `miniprogram/` 文件夹，其中包含 `project.config.json`，AppID 已填写。无需另开云开发套餐，无需构建 npm。
3. 编译后先检查文字草稿，重启应保留；未连接时可直接投递到本机。投递记录支持显式手动记成事项。连接服务后点击“导入本机投递”才复制至远端，本机原件保留；不同空间不自动混合。
4. 此项目默认开启域名校验。开发工具模拟器如需访问本机 HTTP，需要按工具的本地调试设置配置；不要将开发调试设置用于体验/正式环境。真实 iPhone 需要可访问的 HTTPS 服务地址与正确的服务器域名配置，手机上的 `127.0.0.1` 指的是手机自身。

不需要生成或填写 AppSecret；此阶段通过自己的同步服务访问口令签发设备令牌，尚未接微信登录。AppSecret 和模型密钥均不得放入小程序工程。

## 启动独立本地同步服务

在仓库根目录使用 Node.js 24.x：

```powershell
Copy-Item .env.sync.example .env.sync
# 编辑 .env.sync，把 SYNC_PASSWORD 设置为自己生成的至少 12 位随机口令。
npm run sync:start
```

默认只监听 `127.0.0.1:8788`，数据库为 `data/sync-v2/workspace.sqlite`。它与旧服务的 `8787` 和 Windows 个人资料目录相互独立，不会自动导入已有资料，也不会读取模型密钥或调用 AI。

在开发工具中的拾序“连接”页填 `http://127.0.0.1:8788` 和上述个人服务访问口令，连接后再投递文字。口令不会留在手机；有时效的设备令牌保存在小程序本地。服务地址不同会使用不同本地工作区，不自动混合资料。当前服务存在未同步操作时不能直接切换地址。

正式访问条件、AI 类目和备案路线尚需核对；不要把“模拟器能请求本地服务”当成“可以正式发布”。

## 验证与边界

发布前开发分支在首页增加“AI 连接”，在设置中区分未连接、服务端 AI 未启用和已可用；可展开接入说明、刷新整理与事项对话能力。手机不填写 API 密钥，维护者在服务器的独立配置中设置 `SYNC_AI_ENABLED=true`、`DEEPSEEK_API_KEY` 和可选 `DEEPSEEK_MODEL`，按部署流程重启并核对能力。Windows 本机密钥不会自动上传，完整两端共用服务端队列仍待适配。当前云端 AI 保持关闭，本轮没有读取个人密钥或产生真实模型调用。

连接设置可再次点击关闭，返回原来的桶/世界；鲸鱼每次点击重播同源完整音频。详见 [双端验收记录](../docs/release-acceptance-2026-10-24.md)。

```powershell
npm run test:sync
npm run mini:check
```

测试使用虚构资料、临时数据库与测试口令，启动服务后会关闭并清理隔离目录，不调用模型。Node 中的页面生命周期验证不是微信运行时或 iPhone 真机测试。

修改桌面卡片规则、皮肤或整理/对话规则后运行 `npm run mini:build` 更新生成副本；CI 拒绝过期副本。AI 服务需要在服务端同时配置 `SYNC_AI_ENABLED=true` 和 `DEEPSEEK_API_KEY`，密钥不放入小程序；实际调用会产生费用。后台队列中断不会自动重新调用，需在任务状态核对后手动重试。

新版本下载完成后只显示提示。更新前保存草稿，正在同步时等待；未同步操作持久保留，重启后重试。实际平台更新仍需上传新版本并经过对应发布流程，修改后端不能替代小程序客户端发布。

服务接口与后续迁移任务见 [实施记录](../docs/miniprogram-implementation.md) 和 [迁移计划](../docs/archive/miniprogram-migration-plan-2026-10.md)。
