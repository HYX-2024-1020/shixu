# 拾序 Shixu

**把零散的事，安放在一起。** 为大学生活设计的事务与灵感收纳工具，适配手机和电脑，可安装为 PWA。

> 项目处于 0.1 版本。默认不需要登录即可使用；自然语言 AI 与跨设备同步需要你配置自己的服务。没有内置共享密钥，不会自动上传个人事项。

## 开始使用

在线备用入口：[打开拾序](https://hyx-2024-1020.github.io/shixu/)。此入口只公开程序文件，个人内容仍保存在浏览器，或同步到你自己配置的 Supabase。

在应用里点 **随手记一笔**，粘贴通知、作业要求或简短灵感。点击 **本机提取整理**，核对分类和日期，然后 **确认并收纳**。暂时不想处理时，可以先放收集箱。

- **生活概览 / 今天**：查看到期与逾期事项，完成或撤销，设置每日参考目标。
- **日程**：按周查看事项，选择某一天新增记录。
- **我的项目**：把相关事项归到同一个项目，查看进度。
- **灵感花园**：保存点子，生成通用思考提纲，或发送给 AI 展开。
- **日常习惯**：按本地日期打卡、撤销，查看最近七天与累计记录。
- **收集箱 / 归档 / 回收站**：确认新记录、归档、恢复误删事项。
- **搜索**：全文搜索标题、原文、标签、项目。`Ctrl/Cmd + K` 搜索，`N` 新建，输入框中 `Ctrl/Cmd + Enter` 本机整理。
- **专注计时**：25 分钟计时、暂停、继续。仅在页面打开时工作，不提供后台系统推送。

手机使用 Safari / Chrome 打开部署地址，通过浏览器菜单添加到主屏幕。电脑使用 Chrome / Edge 的安装按钮。首次完整访问后可离线打开，离线修改保存在设备，连接云同步后联网再同步。离线能力需要 HTTPS（本机 localhost 也可）。

iPhone 请在 Safari 打开在线入口，点“分享 → 添加到主屏幕”；若出现“作为网页 App 打开”，保持开启。添加后从新图标重新打开，在“设置与数据 → 偏好设置”确认“离线资源已就绪”。不同 iOS 版本、浏览器与主屏幕 App 可能使用不同的数据空间，需要在实际使用的空间重新登录云同步或导入备份。

安装后的应用外壳和按需页面优先从本机缓存读取，不再每次等网络失败才加载。未缓存资源的网络等待最多 8 秒。首次安装、获取新版、AI 与云同步仍需要正常网络；这不能修复运营商到 GitHub Pages 的连接问题。若系统回收或用户清除了网站数据，也需要重新联网准备。电脑上的 `localhost` 服务随进程停止或电脑休眠会失效，不是手机可访问的长期托管地址。

## 本机运行

需要 Node.js **24.0 或更高版本**。

```bash
npm ci
npm run dev
```

打开终端显示的 `http://localhost:5173`。此地址只在当前电脑上有效；手机使用请部署到 HTTPS 域名。Windows 可直接双击项目内的 `启动拾序.cmd`（首次会安装依赖）。

```bash
npm run test     # 日期解析、备份加解密与输入验证
npm run build    # TypeScript 检查、生产构建、离线预缓存
npm run preview  # 生产包预览，http://localhost:4173
```

浏览器集成测试默认在本机 Edge 上运行；CI 使用 Chromium：

```bash
npm run test:e2e
```

## 文件提取

在记录窗口点 **从文件提取文字**。支持 UTF-8 / GB18030 的 TXT、Markdown、CSV，DOCX 正文，文字型 PDF。最多 15 MB、PDF 最多 100 页、提取后最多 6 万字。旧版 DOC、加密文档、扫描件 OCR、图片、复杂表格及脚注暂不支持。

文件原件不会上传。DOCX 只读取正文文本节点，不渲染文档内 HTML；PDF 通过独立 worker 提取文字。文件中的版式、表格关系可能丢失，因此务必核对原始通知。复杂文件可能需要更长时间。

## AI 整理与灵感展开

在 **设置与数据 → AI 整理** 填写兼容 Chat Completions 的 API 根地址、模型 ID 与密钥。根地址例如 `https://your-provider.example/v1`，应用会追加 `/chat/completions`。

- API 必须使用 HTTPS，或本机 `http://localhost`；服务需要允许浏览器跨域请求。
- 只有点击 **发送给 AI 整理 / 展开** 时才发送当前文字。AI 可能产生费用，请使用自己的服务与额度。
- 每次 AI 整理最多 2 万字，不会静默截断长文。一次最多返回 50 条事项。
- **API 密钥只存当前页面内存**，刷新或切换账号即清除。不写入数据库、导出文件、代码或 Git。
- 长期使用建议配置自己的受保护代理，切勿把管理员密钥或服务端密钥放进前端配置。
- 本机模式是确定性规则分类、日期识别和原文重点摘录；通用灵感提纲不包含个性化推理。AI 输出为建议，重要日期仍需用户确认。

## 开启手机电脑同步

1. 在 [Supabase 控制台](https://supabase.com/dashboard) 创建自己拥有的项目。
2. 在 SQL Editor 中执行 [supabase/schema.sql](supabase/schema.sql)。它创建事项表、RLS 策略及同步 RPC，只允许登录用户读写自己的数据。
3. 在项目设置里取得 Project URL 与 **publishable / anon 公钥**。不要使用 `service_role` 或 `sb_secret_`。
4. 在应用 **设置与数据 → 登录与同步** 填写 URL 和公钥，注册邮箱账号，按邮件提示确认，再登录。
5. 在另一台设备打开同一应用地址，填写相同项目配置、登录同一账号。

只有勾选 **把当前本机空间的事项合并到此账号** 才会首次上传本机空间。云端账号有各自独立的本机缓存；退出后回到独立的本机空间，不会把前一个账号的内容带给下一个账号。配置和登录会话存于当前浏览器本地存储，导出不包含它们。公共设备退出后也请清除本站浏览器数据。

同步在修改后约 1 秒触发，也每 30 秒检查、窗口重新聚焦或联网时检查。后台关闭应用时不会继续运行。对同一事项采用最后修改时间获胜；请让设备时钟保持准确。同时编辑同一事项可能覆盖旧版本，重要内容请定期备份。偏好与 AI 设置按设备保存，不随账号同步。

若未配置你自己的 Supabase 项目，应用明确显示“本机保存”；不会假装云同步已经开启。项目没有预设数据库，也不会代替你创建或购买云资源。

参考：[Supabase 密码登录](https://supabase.com/docs/guides/auth/passwords)、[行级访问控制](https://supabase.com/docs/guides/database/postgres/row-level-security)、[数据库函数](https://supabase.com/docs/guides/database/functions)。

## 备份与隐私

在 **数据与备份** 导出 JSON，或使用至少八位密码生成 AES-256-GCM 加密备份（PBKDF2-SHA256，250,000 次迭代，随机盐与 IV）。密码丢失无法恢复。导入前会校验格式、日期、重复 ID，确认后合并较新的事项，不会清空已有数据。备份含事项与展示偏好，不含接口配置、密钥、账号会话。

**浏览器本机数据库本身不额外加密**；保护设备与浏览器账号。清除网站数据或更换域名会影响离线缓存，请提前导出备份。同步数据存于你配置的 Supabase，不是端到端加密；服务提供方与数据库管理员可能访问内容。

无广告、无分析埋点、无遥测、无第三方字体。详见 [PRIVACY.md](PRIVACY.md) 与 [SECURITY.md](SECURITY.md)。

`.gitignore` 排除了 `.env*`、运行配置、构建输出、备份目录、临时测试结果等。**不要把个人备份或文件放在源码目录后提交**；文件名的忽略规则不可能识别所有个人内容。仓库示例全部为虚构数据。

## 部署

`npm run build` 后把 `dist/` 部署到支持 HTTPS 的静态站点服务，挂在域名根路径 `/`；无需后端。所有路由都在同一页，静态托管只需正常提供 `index.html` 和资源文件。`sw.js` 建议使用 `Cache-Control: no-cache`，`assets/` 中带 hash 的文件可使用长期缓存。

本项目在 Sites 的发布配置按部署环境保存，不放入公共仓库。开源用户可使用任意静态托管服务。部署到子路径时，构建前设置 `VITE_BASE_PATH`，例如 GitHub Pages 使用 `/shixu/`；资源、PWA 和离线缓存均支持此路径。仓库附带 GitHub Pages 自动发布工作流，只上传 `dist/` 程序文件，不上传个人数据。

不同域名的浏览器空间相互隔离。更换入口后，若原来已有数据，请从原入口导出备份再导入，或在新入口配置相同的 Supabase 项目并登录同步。

## 技术结构

React + TypeScript + Vite，IndexedDB 本机持久化，Service Worker 离线预缓存，PDF.js 文件提取，fflate 解压 DOCX，Lucide 图标，Supabase Auth + PostgreSQL RLS / RPC 可选同步。重型文件处理代码按需加载。

```text
src/organize.ts       本机提取与 AI 结构化整理
src/files.ts          本机文件文字提取与重点摘录
src/storage.ts        数据库、备份验证与加密
src/cloud.ts          登录、刷新会话与同步传输
src/useWorkspace.ts   独立账号空间、离线状态与自动同步
src/App.tsx           概览、日程、项目、灵感与习惯
supabase/schema.sql  云端访问隔离与原子合并
e2e/                 手机与桌面浏览器集成验证
```
